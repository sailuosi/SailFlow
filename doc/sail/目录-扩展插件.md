# 扩展插件目录（pure · ext · biz · 宿主）

> 状态：现行清单（2026-11-04）  
> 范围：`sailflow/src` 下 **pure / ext / biz** 可插拔能力 + 宿主 `sleveen-admin/backend/__KEEP_sailflow__`  
> 挂载约定：[最佳实践-宿主能力包UseXxx.md](./最佳实践-宿主能力包UseXxx.md) · 分层：[架构设计-项目依赖与分层.md](./架构设计-项目依赖与分层.md)

路径均相对仓库根：`sailflow/...`、`sleveen-admin/...`。

---

## 0. 怎么读

| 列 | 含义 |
|----|------|
| **挂载** | `UseXxx` / `AddXxx` / `client.useXxx` |
| **契约** | 宿主或业务实现时对接的接口 |
| **核心代码** | 入口扩展 + 主实现类（非穷尽文件树） |

插槽未挂载时引擎快速失败并提示对应 `UseXxx`（刻意行为）。

## 5. 宿主默认组合顺序（摘录）

```text
UseBizJson → UseBizRules → UseBizAction → UseBizAssignees → UseBizData
  → UseDataLifecycleFromConfig → UseDebugConsoleHook → UseFlowEventFileLog
  → UseFormBizLifecycleHook → UseNodePolicyTimeoutStamp → UsePortalScheduleTaskNotifier
  → UseDatabase / UseBizLocalize / UseResource / UseForm / UseSchema / UseBizAI
Build 后：
  UseSleveenOrgLookups → UseSleveenNodePolicyAssignee
MS DI：
  AddSailFormBiz · AddSailOperationHandlers · AddSailNodePolicyJobs
```

出处：`sleveen-admin/backend/__KEEP_sailflow__/src/Hosting/sailflowHostSetup.cs`。

## 6. 扩展点速查（要加新插件时）

| 要加什么 | 挂哪里 | 参考实现 |
|----------|--------|----------|
| 新算人 Type | `UseAssign` → `AddResolver<T>` 或宿主 `useAssigneeResolver` | pure Resolvers / `SleveenRoleGroup*` |
| 空人/同人后置 | `AddEmptyAction` / `AddFilter` | Host `NodePolicy*` / `SameAsStarterFilter` |
| 自动审批执行 | 锚点 + Job（禁止 Filter 内嵌套 Run） | `AutoApproveAnchorWorker` |
| 新流出判定 | `useLeaveJudge` | `CaptainLeaveJudge` |
| 发送前校验 | `AddGate` | `samples/external` · `FinancePreSendGate` |
| 下一跳写袋 / 求值 / 裁候选 | `UseNextStepRoute` | `samples/external` 样例 Prepare/Filter；定型见特性说明-下一节点过滤器 |
| 业务副作用 | `AddHook` | `SailFormBizLifecycleHook` |
| BestEffort 可丢副作用（Channel 串行） | `BestEffortFlowHookBase` + `AddHook` | msg 骨架；admin `UseFlowEventFileLog` |
| 待办通知（Reliable/Outbox） | `AddNotifier` + Drain | `ReliableTaskNotifierBase`；admin `UsePortalScheduleTaskNotifier` |
| 新办理按钮 | `ISailOperationHandler` + `AddSailOperationHandlers` | `TransferOperationHandler` |
| 新业务表单 | `ISailFormBizHandler` + `AddSailFormBiz` | Leave / Dynamic |
| 脚本语言 | Action 插槽 | `UseIronPython` |
| Python 连线条件求值 | `UseNextStepRoute` → `AddConditionEvaluator<PythonConditionEvaluator>`（**不**随 UseIronPython） | `action/src/Python/PythonConditionEvaluator.cs` |
