# 专题 · 同人、重复与跳过

> 状态：**已落地**（引擎 R10 契约 + 宿主 Filter/Hook/Job；2026-11-16 主路径改 Hook→`RunProcess`）  
> 用途：把「同人 / 重复 / 跳过」写清；**含义后紧跟分层**（引擎哪一层 / 钩子 / 宿主定义 / `UseXxx`）。  
> 范围：节点 `sf:NodePolicy` · 流程 Extra `autoApprovalType` · `DedupUsersFilter` · AutoApprove Outbox/Job。  
> 关联：[特性说明-待办人管道.md](../特性说明-待办人管道.md) §11 · [联调清单](../dev/联调清单-产品缺口.md) §A · 宿主 `UseSleveenNodePolicyAssignee` / `UseNodePolicyAutoApproveHook` / `UseProcessExtraRuntime`

**分层列约定：** 归属（引擎/宿主）· 层（管道 Filter / Hook / Job…）· 钩子/回调 · 宿主定义 · UseXxx。

## 1. 一句话

### 1.1 含义

**「同人 / 重复 / 跳过」都不是新 Resolve Type**——定范围仍走 `sf:assigneeResolve`；策略挂在 **Filter / EmptyAction / 发送成功 Hook → AutoApprove 锚点 → Job `RunProcess`**。先建 Waiting 留痕迹，再异步代办。

| 产品说法 | 配置落点 | 触发层（摘要） |
|----------|----------|----------------|
| 与**发起人**同一人 | `assignStartUserHandlerType` | Filter 换人 / Hook 跳过 |
| 流程中**重复出现** | Extra `autoApprovalType` | Dedup Hook |
| 节点**整段自动通过/拒绝** | `approveType` | Filter 拒绝人 / Hook 通过 |
| 算人**空**自动通过 | `assignEmptyHandlerType=1` | EmptyAction + Hook |
| 名单**重复 UserId** | （管道） | `DedupUsersFilter`（非免批） |
| 跳过表达式 | `skipExpression` | **落盘未消费** |

### 1.2 分层说明（总览）

| 能力 | 归属 | 层 | 钩子/回调 | 宿主定义 | UseXxx |
|------|------|----|-----------|----------|--------|
| 定范围 | 引擎槽 + 宿主 Resolver | 时刻 A Resolve | `IAssigneeResolver.Resolve` | `sf:assigneeResolve`、组织 Lookup | **`UseBizAssignees`** + **`UseSleveenOrgLookups`** |
| 同人=3 换人 | 宿主 Filter | 时刻 A′ Filter order 10 | `SameAsStarterFilter.Apply` | 读 NodePolicy；再调 Registry | **`UseSleveenNodePolicyAssignee`** |
| 同人=2 / 空人=1 / approveType=2 入队 | 宿主 Hook | FlowHook Sync | 事件 **`OnProcessStarted` / `Continued` / `Resent`** → `SailNodePolicyAutoApproveHook` | 读 NodePolicy + Waiting 待办 | Builder：**`UseNodePolicyAutoApproveHook`** |
| 流程去重入队 | 宿主 Hook | FlowHook Sync | 同上三事件 → `SailProcessExtraDedupHook` | ExtraJson `autoApprovalType` | Builder：**`UseProcessExtraRuntime`** |
| 空人=1 写策略人 | 宿主 EmptyAction | 时刻 A′ 空集 | `NodePolicySkipEmptyAction.Handle` | `Sail:PolicySkip:*` | **`UseSleveenNodePolicyAssignee`** |
| approveType=3 | 宿主 Filter | Filter order 0 | `NodePolicyApproveTypeFilter.Apply` | 策略拒绝人常量 | 同上 |
| 列表去重 | 引擎 Builtin | Filter order 60 | `DedupUsersFilter.Apply` | 宿主 AddFilter | 同上 |
| 代办执行 | 引擎 Worker + 宿主 Job | Outbox → `AutoApproveAnchorWorker` → `RunProcess` | 非 FlowHook；Job 轮询 | `SailNodePolicyJobWorker` | **`UseNodePolicyTimeoutStamp`** 等同包 HostedService；AnchorStore 在 NodePolicyAssignee |
| 退回关同人 | **引擎** | Backward 建任务 | `AllowSameAsStarterPolicy=false` | — | 引擎内建 |

```csharp
// SailflowHostSetup（与本专题相关）
.UseBizAssignees()
.UseNodePolicyAutoApproveHook()   // 同人/空人/approveType 入队
.UseProcessExtraRuntime(sp)       // 含 DedupHook
// Build 后：
client.UseSleveenNodePolicyAssignee(configuration); // Filter/EmptyAction/Dedup/AnchorStore
// HostedService：SailNodePolicyJobWorker（Drain 锚点）
```

**正交：** 节点同人 ⊥ 流程去重；同人=2 ⊥ 同人=3；列表 Dedup ≠ Extra 去重。

## 2. 勿混：问题分层（产品）

| 问的是 | 正确挂载 | 错误做法 |
|--------|----------|----------|
| 这节点该找谁 | Resolve | 新 Resolve Type 表达同人 |
| 是否全是发起人 | SameAsStarter Filter / AutoApproveHook | Leave 里跳过 |
| 本实例是否办过 / 是否连续 | DedupHook | 与 NodePolicy 抢同一开关 |
| 如何代点同意 | Outbox + Job `RunProcess` | Filter/Hook 内同步 Run |

## 3. 产品配置（含义 → 分层）

### 3.1 节点 · 与发起人同一人

#### 含义

**UI：** 节点配置「审批人与发起人为同一人时」→ `assignStartUserHandlerType`（默认 1）。

| 值 | 产品 | 运行时摘要 |
|----|------|------------|
| 1 | 自己批 | 不干预 |
| 2 | 自动跳过 | 保留 Waiting；Hook 全员=发起人则入队 |
| 3 | 换人策略 | Filter 再 Resolve（默认 `deptBoss`） |

#### 分层说明

| 值 | 归属 | 层 | 钩子/回调 | 宿主 | UseXxx |
|----|------|----|-----------|------|--------|
| 2 | 宿主 Hook | 发送成功 FlowHook | `OnProcessStarted/Continued/Resent` → AutoApproveHook（`SameAsStarterSkip`） | NodePolicy JSON | **`UseNodePolicyAutoApproveHook`** + JobWorker |
| 3 | 宿主 Filter | A′ Filter | `SameAsStarterFilter.Apply` → Registry Resolve | `assignStartResolveType/Params`；`Sail:DeptLeaderRoleIds` | **`UseSleveenNodePolicyAssignee`** + **`UseSleveenOrgLookups`**（deptBoss） |
| 退回 | 引擎 | Backward | `AllowSameAsStarterPolicy=false` 使 Filter 直接 return | — | 引擎 |

---

### 3.2 流程 · 重复出现自动过

#### 含义

**UI：** 更多设置「自动去重」→ Extra `autoApprovalType`：0 无 / 1 曾办过 / 2 连续同人。

#### 分层说明

| 步骤 | 归属 | 层 | 钩子/回调 | 宿主 | UseXxx |
|------|------|----|-----------|------|--------|
| 配置 | 宿主 | ExtraJson | — | `sf_process_meta`、`ExtraSettings.vue` | 元数据保存 |
| 入队 | 宿主 Hook | FlowHook Sync | **`OnProcessStarted/Continued/Resent`** → `SailProcessExtraDedupHook` | 读 Completed 历史 | **`UseProcessExtraRuntime`**（Feature Dedup） |
| 执行 | 引擎+宿主 Job | Outbox Drain | `AutoApproveAnchorWorker` → `RunProcess` | JobWorker | 同 §1.2 |

与 NodePolicy 同人**正交**（可同时入队；先成功者办结，其余常 `AutoApproveSkipped`）。

---

### 3.3 节点 · 审批类型（整段跳过）

#### 含义

`approveType`：1 人工 / 2 自动通过 / 3 自动拒绝。现行=**建 Waiting 再代办**（提示文案若写「不建待办」以本专题为准）。

#### 分层说明

| 值 | 归属 | 层 | 钩子/回调 | UseXxx |
|----|------|----|-----------|--------|
| 2 | 宿主 Hook | FlowHook | AutoApproveHook（`ApproveTypeSkip`） | **`UseNodePolicyAutoApproveHook`** |
| 3 | 宿主 Filter | Filter order 0 | `NodePolicyApproveTypeFilter` 换策略拒绝人；Job 侧拒绝 | **`UseSleveenNodePolicyAssignee`** + JobWorker |

---

### 3.4 空人自动通过

#### 含义

`assignEmptyHandlerType=1`：空集写入策略跳过人，再 Hook 入队（意见「空人策略：自动通过」）。`=2` 为 R4 拒绝，不是跳过。

#### 分层说明

| 步骤 | 归属 | 层 | 钩子/回调 | 宿主 | UseXxx |
|------|------|----|-----------|------|--------|
| 选型 | 宿主 | EmptyActionSelector | — | PolicyBag | **`UseSleveenNodePolicyAssignee`** |
| 写人 | 宿主 | EmptyAction | `NodePolicySkipEmptyAction.Handle` | `Sail:PolicySkip:UserId/Name` | 同上 |
| 入队 | 宿主 Hook | FlowHook | AutoApproveHook（`EmptySkip`） | 认策略人 SignId | **`UseNodePolicyAutoApproveHook`** |

---

### 3.5 跳过表达式（未消费）

#### 含义

`skipExpression` 设计器可填。

#### 分层说明

| 归属 | 层 | 钩子 | UseXxx |
|------|----|------|--------|
| 仅宿主落盘 | NodePolicy JSON | **无**求值、**无** Hook | **无**运行时启用项 |

---

### 3.6 列表去重（非免批）

#### 含义

同一 Resolve 结果按 `UserId` 去重，少建重复待办，**不** AutoApprove。

#### 分层说明

| 归属 | 层 | 钩子/回调 | UseXxx |
|------|----|-----------|--------|
| 引擎 Builtin + 宿主挂载 | Filter order 60 | `DedupUsersFilter.Apply` | **`UseSleveenNodePolicyAssignee`** 内 `AddFilter` |

## 4. 运行时链路

```text
时刻 A · 建待办（TryResolveForTaskCreate）
  Resolver 定范围
  → Count==0？ EmptyAction（空人=1 → 策略跳过人）
  → Filters：
       order 0  NodePolicyApproveTypeFilter   （approveType=3 换拒绝人；=2 放行）
       order 10 SameAsStarterFilter           （仅 type=3 换人；type=2 不清人）
       order 50 SurrogateAssigneeFilter
       order 60 DedupUsersFilter              （名单去重）
  → 落库 Waiting 待办（正常痕迹）

发送成功 Hook（仅 Started / Continued / Resent）
  SailNodePolicyAutoApproveHook
    approveType=2 → 全 Waiting 入队
    同人=2 且全部 SignId=发起人 → 入队
    空人=1 且全部为策略跳过人 → 入队
  SailProcessExtraDedupHook
    autoApprovalType 1|2 命中历史 → 入队
  → HookOutboxAutoApproveAnchorStore（与发送同库事务）

不订阅：SendBack / Reject / Withdraw / Reverse / Jump …
  → 退回落点不会「自动回来」

Job · SailNodePolicyJobWorker
  AutoApproveAnchorWorker.ProcessPendingAsync
    → 以 PreferUserId 身份 RunProcess（固定 sail.comment）
    → 失败 AutoApproveFailed，待办保留给人办
  （可选）Sail:PolicySkip:LegacyDrain=true → 扫魔法 skip 待办兜底
```

**退回边界：** Backward 建任务时引擎置 `AllowSameAsStarterPolicy=false` → `SameAsStarterFilter` 直接 return；同人=3 换人亦不在退回落点生效。

## 5. 命中矩阵（速查）

| 场景 | 同人=1 | 同人=2 | 同人=3 | 去重=0 | 去重=1 | 去重=2 | approveType=2 |
|------|--------|--------|--------|--------|--------|--------|---------------|
| 办理人 ≠ 发起人 | 人工 | 人工 | 人工 | 人工 | 若曾办过则过 | 若连续同人则过 | **过**（整节点） |
| 办理人 = 发起人（全员） | 人工 | **过** | **换人** | 人工 | 若曾办过则过 | 若连续则过 | **过** |
| 算人为空且空人=1 | — | — | — | — | — | — | （策略人）过 |
| SendBack 落点 | 人工 | 人工（不开同人） | 不换人 | 不去重入队* | 不去重入队* | 不去重入队* | 不入队* |

\* Dedup / NodePolicy AutoApprove Hook **不订阅** SendBacked；退回后须人办或再次正向发送。

**同时命中：** 同人=2 与 去重=1 可对同一待办各写锚点；Job 幂等按锚点消费，首次成功办结后其余应 `AutoApproveSkipped`（无 Waiting）。

## 11. 红线与余债

**红线**

1. 禁止把同人/重复注册成 Resolve Type。  
2. 禁止在 Filter / EmptyAction / Hook 内同步 `RunProcess`。  
3. 禁止另开第二套 AutoApprove Drain 与 `SailNodePolicyJobWorker` 双开（浪费 reclaim；见 `UseSleveenAssigneeAutoApproveJob` 警告）。  
4. SignTogether **禁止**零 Performer 自动过。  
5. 退回路径默认关闭同人换人/跳过策略。

**余债**

| 项 | 说明 |
|----|------|
| `skipExpression` | 落盘未求值 |
| 设计器 approveType=2 提示文案 | 与「建 Waiting 再代办」现行不完全一致，宜改提示 |
| 同人与去重双锚点 | 行为可接受；若产品要「互斥优先」需另拍板 |
| 会签部分人=发起人 | 同人=2 要求**该活动全部** Waiting 的 SignId=发起人；部分同人不会整节点跳过 |
