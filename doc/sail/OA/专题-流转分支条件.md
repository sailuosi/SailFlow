## 0. 一句话与划界

### 0.1 含义

**流转分支条件** = 当前节点往下走时，**哪些 `sequenceFlow` / 网关出口可达**——由图上表达式 + 运行时**条件袋**求值决定；多候选时前端可自选，发送再裁剪。  
**不是**「谁来办」（Assignee），**不是**「凑齐几人过」（Leave），**不是**「推进前拒发」（Gate）。

| 口语 | Sail 锚点 | 本专题？ |
|------|-----------|----------|
| 金额大于一万走财务 | BPMN `conditionExpression` + Conditions | ✅ |
| 排他/包容/并行网关 | XOr / Or / And Split… | ✅ |
| 通过走 A、驳回走 B | `ApprovalOrSplit` | ✅ |
| 自动补单据字段进条件袋 | Client `IfCondition*`（Prepare） | ✅ |
| 换条件求值引擎（LINQ/Python） | `IConditionEvaluator` | ✅ |
| 隐藏无权看见的出口 | `INextStepFilter` | ✅ |
| 下一节点找谁 | Resolve / Assignee Filter | ❌ |
| 会签几人过 | Leave | ❌ |
| 强制跳到某节点 | Jump / Skip | ❌ 命令路径 |

```text
要决定「走哪条线」？
 ├─ 字段分流写在图上 conditionExpression     → §1
 ├─ 运行时把 amount/dept 填进条件袋           → §2（请求级 / Client Prepare）
 ├─ 表达式怎么算                              → §3 Evaluator
 ├─ 多出口怎么露/藏                           → §4 Filter（预览≡发送）
 └─ 并行必达支 / 默认支 / 优先级              → §1.3 网关
不要：
 ├─ 金额分流塞进算人 Type / Leave
 ├─ 用 Gate 注入 Conditions 或改候选
 └─ 用 IronPython ScriptMethod 冒充连线求值
```

### 0.2 分层说明（总览）

| 能力 | 归属 | 层 | 钩子/回调 | 宿主定义 | UseXxx |
|------|------|----|-----------|----------|--------|
| 连线表达式 | **设计** | BPMN Transition | — | `conditionExpression`；`sf:groupBehaviours` | 设计器落盘 |
| 条件袋写入 | **宿主/调用方** | 请求级 RunBuilder · Client Prepare | **无 FlowHook**；管道 R0 | 办理页字段 / 单据读数 | `IfCondition` · **`UseNextStepRoute`→IfCondition*** |
| 求值 | **引擎** runtime/ext | `IConditionEvaluator` 有序链 | `TryEvaluate`→`bool?` | 默认 LINQ | **`UseSailRuntimeDefaults`** 或 `AddConditionEvaluator` |
| 结构演算 | **引擎** | `ProcessModelBPMNCore` | 出边过滤 → 网关展开 | 纯图；不进 Mediator 改调度 | 引擎内建 |
| 候选处置 | **引擎管道** | R1 `INextStepFilter` | Annotate/Prune；AndSplitGuard | 权限隐藏等 | `UseNextStepRoute`→`AddFilter` |
| 预览/发送 | **引擎+宿主 UX** | `GetNextStepInfo` / Runtime 树 | 同源管道（N2） | 办理台下一步；`NextActivityPerformers` | API 查询 + 发送 |

```csharp
.UseSailRuntimeDefaults()   // 或 UseBizRuntimeDefaults：挂 LinqDynamicConditionEvaluator
.UseNextStepRoute(r =>
{
    r.IfCondition<OrderAmountPrepare>(o => { o.ProcessCodes = new[] { "EXPENSE" }; });
    r.AddFilter<HideUnauthorizedBranchFilter>(…);
});
// 单次办理：
.CreateRunBuilder().IfCondition("amount", "15000")…
```

## 1. 图上配置（连线 + 网关）

### 1.1 含义

分流规则**优先写在 BPMN**（N6）：连线条件文本 + 网关类型/默认支/优先级。运行时只负责填变量并求值。

```xml
<bpmn:sequenceFlow …>
  <bpmn:conditionExpression>amount &gt; 10000</bpmn:conditionExpression>
</bpmn:sequenceFlow>
```

| 无条件 | 有条件且袋非空 | 有条件但袋空 |
|--------|----------------|--------------|
| 线**始终可达** | Evaluator 链求值 | **不可达**（易踩坑） |

有条件却**未注册**任何 `IConditionEvaluator` → **抛异常**（不再静默）。

### 1.2 分层说明

| 步骤 | 归属 | 层 | 钩子/回调 | 宿主定义 | UseXxx |
|------|------|----|-----------|----------|--------|
| 设计连线条件 | 宿主设计器 | BPMN | — | `ConditionDetail.ConditionText`；Type 现固定 Expression | 落盘 |
| 网关附属 | 宿主设计器 | `sf:groupBehaviours` | — | `defaultBranch` / `priority` / Approval | 落盘 |
| 单线判定 | 引擎 | `IsValidTransition` | 调 Evaluator 链 | — | 须已挂 Evaluator |
| 结构展开 | 引擎 | `GetNextActivityTreeListCore` | Prepare→条件→网关 | 不改内核插业务 | — |

### 1.3 网关语义（产品）

| 网关 | 行为 |
|------|------|
| **AndSplit / AndSplitMI** | **所有**出边都走，**不看**连线条件；Filter **禁止**静默删必达支 |
| **OrSplit** | 条件为真的都走；全假 → `defaultBranch` |
| **XOrSplit** | 按 `priority` 排序，取**第一条**为真的线 |
| **ApprovalOrSplit** | 按通过/驳回选边（≠ RejectMode 配置落点） |
| **Join** | 合并后再对出边条件过滤继续 |

并行必达支要藏起来 → 用 **Gate Reject** 或产品告警，**不要**靠 NextStep Filter 偷删（N5）。

## 2. 条件袋（变量从哪来）

### 2.1 含义

表达式里的 `amount`、`dept` 等键，来自**同一** `Conditions` 袋（可与流程变量合并）。两档写入**同义、寿命不同**（N11）：

| 档 | API | 寿命 |
|----|-----|------|
| **请求级** | `RunBuilder.IfCondition(key, value)` | 这一次查询/发送 |
| **Client 级** | `UseNextStepRoute` → `IfCondition*` → `INextStepPrepare` | 每次结构演算前自动写 |

后写可覆盖先写。键名必须与表达式一致。

### 2.2 分层说明

| 步骤 | 归属 | 层 | 钩子/回调 | 宿主定义 | UseXxx |
|------|------|----|-----------|----------|--------|
| 办理页补键 | 宿主 UX → API | 请求级 | — | 表单字段映射进 Runner.Conditions | RunBuilder |
| 单据自动补 | 宿主 Prepare | 管道 R0 | Options Match → IsMatch → Prepare | 读业务库按 AppInstanceId | **`UseNextStepRoute`→IfCondition*** |
| 流程变量 | 引擎 | 变量合并 | — | 活动实例变量 | 引擎内建 |
| 运行中改袋 | 引擎服务 | `IEventService.SetCondition` | — | 少用；慎与预览一致性 | — |

Prepare **只写袋**，禁止改候选列表、禁止伪造令牌（N1/N9）。

## 3. 条件求值（`IConditionEvaluator`）

### 3.1 含义

每条 `conditionExpression` 经**有序链**求值：`TryEvaluate` 返回  
- `true` / `false` → 采用并**终止链**  
- `null` → 交给下一 Order（**null ≠ false**）

默认实现：`LinqDynamicConditionEvaluator`（Order 宜偏大作兜底）。Python 等必须是 Evaluator 实现，**不是** ScriptMethod（N15）。

### 3.2 分层说明

| 步骤 | 归属 | 层 | 钩子/回调 | 宿主定义 | UseXxx |
|------|------|----|-----------|----------|--------|
| 默认 LINQ | 引擎 runtime | Evaluator | `TryEvaluate` | — | **`UseSailRuntimeDefaults`** / `UseBizRuntimeDefaults` |
| 自定义/Python | ext | Evaluator Order 更小 | 前缀如 `python:` 可优先 | 按需注册 | `UseNextStepRoute`→`AddConditionEvaluator` |
| 无 Evaluator | 引擎 | `NextStepConditionRequire` | 有条件时硬失败 | — | 必须先挂 |

## 4. 候选 Filter 与预览≡发送

### 4.1 含义

结构演算后得到**多个目标节点**时：

1. **Filter** 可标注 `Disabled` / `Required` / `ReasonCode`，或裁掉非法支（Or/XOr/自选集合主战场）。  
2. **预览** `GetNextStepInfo` 与 **发送** `GetNextActivityTreeListRuntime` **共用同一管道**（N2）。  
3. 发送最终以 Runner `NextActivityPerformers` 键集合为准二次过滤。  
4. 收成 **0 候选** → 可诊断失败，**不得**静默挑一条（N4）。

### 4.2 分层说明

| 步骤 | 归属 | 层 | 钩子/回调 | 宿主定义 | UseXxx |
|------|------|----|-----------|----------|--------|
| 注册 Filter | 宿主 | `INextStepFilter` | Options Match → Filter | 权限/强制单选/排序 | `UseNextStepRoute`→`AddFilter` |
| And 守护 | 引擎 | `AndSplitGuard` | 禁静默删必达支 | — | 管道内建 |
| 预览 | 引擎+宿主 | `GetNextActivityListView` | Annotate NodeView | 办理台展示 Disabled | — |
| 发送 | 引擎 | Runtime 树 Prune | + Performers 裁剪 | 选中出口键 | — |

Filter **不得**插入图上不可达的 ActivityId（N9）。

## 5. 与邻域划界

| 说法 | 别当成 | 正确锚点 |
|------|--------|----------|
| 分支条件 | 算人 Type | Resolve / Assignee Filter |
| 分支条件 | 会签人数 | Leave `completeCount/Rate` |
| 分支条件 | Gate 拒发 | Gate 可拒推进，**不**写 Conditions、不改候选 |
| ApprovalOrSplit | RejectMode | 网关边 vs 驳回落点配置（退回专题对照） |
| NextStep Filter | Assignee `AddFilter` | 改「走哪」vs 改「谁办」；注册门面不同 |
| 条件求值 | IronPython Script 节点 | `IConditionEvaluator` vs ScriptMethod |
| 强制改道 | 条件 Filter 插不可达点 | Jump / SkipDetail |

金额分流等：**禁止**塞进算人 Type（待办人管道红线）。

## 6. UseXxx / 装配清单

| 项 | 本专题作用 |
|----|------------|
| **`UseNextStepRoute`** | 唯一节点计算管道门面：Prepare + Evaluator + Filter |
| **`UseSailRuntimeDefaults` / `UseBizRuntimeDefaults`** | 挂默认 LINQ Evaluator（推荐） |
| `RunBuilder.IfCondition` | 请求级写袋（不废） |
| `r.IfCondition*` / 链式 `ForProcess`… | Client Prepare 糖 |
| `AddConditionEvaluator` / `UseConditionEvaluator` | 求值链 |
| `AddFilter`（**在 NextStepRoute 子 Builder 上**） | 候选处置；≠ `UseAssign.AddFilter` |
| （无）顶层独立 `UseCondition*` 正典 | 求值挂在 NextStepRoute 内，避免管道分裂 |

Match：Options 正典（ProcessCodes / ActivityCodes / Patterns / Order）；`IsMatch` 第二道门（N12）。

## 7. 选型与验收

| 意图 | 用 |
|------|-----|
| 金额/部门字段分流 | 连线 `conditionExpression` + 条件袋补键 |
| 每次自动读单据金额 | Client `IfCondition<Prepare>` |
| 仅本笔提交带变量 | 请求级 `IfCondition` |
| 无条件命中走默认 | OrSplit + `defaultBranch` |
| 互斥只走一条 | XOrSplit + `priority` |
| 通过/驳回不同后续 | ApprovalOrSplit |
| 前端隐藏某出口 | NextStep Filter（预览 Disabled） |
| 并行全开 | AndSplit（别管连线条件） |

| # | 期望 |
|---|------|
| C1 | 有条件无袋 → 线不可达；补 `amount` 后预览与发送一致 |
| C2 | 未挂 Evaluator 且有条件 → 明确异常 |
| C3 | XOr：priority 高且为真的先命中 |
| C4 | Or 全假 → 默认支 |
| C5 | And：Filter 删不掉必达支 |
| C6 | 预览 Disabled 的出口发送也不可静默走通 |
| C7 | Prepare 写入键 / Filter 移除可诊断（N10） |
| C8 | Assignee Filter 不改变可达出口集合 |

## 8. 红线

1. **字段分流优先 BPMN**，勿把可配置规则只写在代码里导致图失真（N6）。  
2. **Prepare ≠ Evaluator ≠ Filter ≠ Gate ≠ Assignee**（N1/N7）。  
3. **预览 ≡ 发送** 同源管道；禁止只滤一边（N2）。  
4. **And 必达支不可静默删**（N5）。  
5. **有条件必须有 Evaluator**；失败可诊断，禁止静默挑支（N4/N10）。  
6. **`bool?` null 仅表示移交**，勿当 false（N13）。  
7. **条件求值 ≠ Script 节点**（N15）。  
8. Filter **禁止**插入不可达节点；强制改道走 Jump/Skip（N9）。
