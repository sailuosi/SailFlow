## 0. 一句话与三分

### 0.1 含义

口语「委托 / 代办」在 Sail 里**不是一个按钮**。先选型：

| 你想要的 | 产品名 | 触发 | 原人 | 办完 |
|----------|--------|------|------|------|
| 这张单交出去，不还回 | **转办** `Transfer` | 办理条 · 单笔 | 关闭 | 对方推进 |
| 这张单请他代点，办完还我 | **委派** `Delegate` | 办理条 · 单笔 | 关闭（责任锚仍在） | **回转原人**，不推进 |
| 出差/休假，之后到我名下的单他也能批 | **委托代批** Surrogate | 「我的委托」配置 · 建任务自动 | **保留** | 谁办谁推进（Leave/计权） |

本专题只展开 **委派** 与 **委托代批**。

```text
临时请人代办？
 ├─ 对着【正在跑的这一张待办】              → §1.A 单笔委派
 ├─ 对着【某一流程定义的今后新待办】        → §1.B 单流程代批配置
 └─ 对着【某一时间段（可叠加流程范围）】    → §2 时段代批
委托关系怎么串？
 └─ §3 委托链（EntrustedTaskId 回转链 ⊥ ProxySignId 代理链）
```

### 0.2 分层说明（总览）

| 能力 | 归属 | 层 | 钩子/回调 | 宿主定义 | UseXxx / 启用 |
|------|------|----|-----------|----------|---------------|
| 委派命令 | **引擎** | `WorkflowService` → Assignee `DelegateLane` → `TaskManager` | Gate=`Delegate`；成功 Hook=`OnProcessDelegated`；路径内 `FireTaskLifecycle(Entrusted)` | 码表 `Delegate`、`DelegateOperationHandler`、办理条 | 引擎命令默认有；宿主 **`AddSailOperationHandlers`** + 节点开按钮 |
| 委派回转 | **引擎** | Mediator 办结 → `TaskManager.TryCompleteAsDelegationReturn` | 挂在 **Run/Approve 办结路径**（非独立 Hook） | 无 | 引擎内建 |
| 委托代批并人 | **宿主 Filter** + **引擎管道槽** | Assignee 时刻 A′：`IAssigneeResolveFilter.Apply` | **无 FlowHook**；在 `TryResolveForTaskCreate` 的 Filter 链 | 表 `sf_surrogate`、CRUD API/页、`SurrogateAssigneeFilter` | Builder：`UseBizAssignees()`；Client：`UseSleveenNodePolicyAssignee`（内 `AddFilter(..., 50)`） |
| 代批计权 | **引擎** assignee | Leave 时刻 B：`EffectiveWeightHelper` | `IActivityLeaveJudge` 读 `LeaveSeatSnapshot` | Host 可写 `EndText` 本地化 | `UseBizAssignees` 提供 Leave/Helper；不另开 Use |
| 转办（对照） | 引擎 | `TransferLane` → `TaskManager.Transfer` | Gate + `OnProcessTransferred`；Manager 内 Entrusted/Created | `TransferOperationHandler` | 同委派 Handler 包；细表 [专题-转办.md](./专题-转办.md) |

装配锚点（宿主）：

```csharp
// SailflowHostSetup（示意）
.UseBizAssignees()                      // 引擎管道骨架
.UseNodePolicyAutoApproveHook()         // 与代批无关（同人/空人）
.UseProcessExtraRuntime(sp)             // 与代批无关（去重等）
// Build 后：
client.UseSleveenNodePolicyAssignee(configuration);  // 挂 SurrogateAssigneeFilter + Dedup…
services.AddSailOperationHandlers();                 // Delegate/Transfer 等办理条
```

## 1. 第一部分 · 单个流程临时委托

### 1.0 含义

「单个流程」有两层，**勿混为一键**：

| 含义 | 机制 | 作用对象 |
|------|------|----------|
| **A. 单笔实例临时** | 办理条 **委派** `Delegate` | **当前**流程实例上的一张待办 |
| **B. 单流程定义配置** | 委托代批行 `ProcessId=某定义` | 之后该定义下**新建**到委托人名下的待办 |

### 1.A 单笔委派（实例级临时）

#### 含义

我是当前节点责任人，临时请人代看/代点——**责任仍在我**；对方办完待办必须回到我手上。办完不还回 → 用转办。

#### 分层说明

| 步骤 | 归属 | 层 | 钩子/回调 | 宿主定义 | UseXxx |
|------|------|----|-----------|----------|--------|
| 办理条点「委派」 | 宿主 | Host UX → `ButtonsOperation` | — | `SailButtonsCatalog.Delegate`（默认关）、选人 UX | 节点 `sf:ButtonsSetting` 启用 |
| HTTP / Handler | 宿主 | API / OperationHandler | — | `DelegateOperationHandler` → `wf.DelegateProcessAsync`；或 `POST …/DelegateProcess` | **`AddSailOperationHandlers`** |
| 事务+锁+Action | **引擎** | `WorkflowService.RunAction` → `DelegateLane` | Gate：`FlowCapabilityPipeline.TryGate(FlowOperation.Delegate)`（Assignee 族时序） | — | 引擎内建；需已 `UseBizAssignees` 等正常装配 |
| 沟通未清拦截 | **引擎** | Assignee `Execute` 前 | `ConsultPendingGuard.TryAllow` | — | 引擎内建 |
| 写库发起 | **引擎** | `TaskManager.Delegate` | 路径内 `FireTaskLifecycle(Entrusted)` + 目标 `Created`；**不**在 Action 再抄 | — | 引擎内建 |
| 命令成功横切 | **引擎** | `AssigneeActionBase` | FlowHook **`OnProcessDelegated`**（`OnFireFlowHook`） | 可 `addHook` 订阅该事件做旁路 | 默认管道；产品 Hook 自挂 |
| 受托人同意 | **引擎** | `RunAction` / Mediator 办结 | **`TryCompleteAsDelegationReturn`**（发现 `EntrustedTaskId`） | — | 引擎内建 |
| 回转后推进？ | **引擎** | 回转路径 | **不** `ContinueForward` | — | — |

#### 产品入口与运行时

| 项 | 值 |
|----|-----|
| 码表 / API | `Delegate` → `DelegateProcess` |
| 字段 | `sf_task.tk_entr_task_id` ← `EntrustedTaskId` |
| 链深 | **1**；禁止套娃 / 自委派 |

```text
发起：原 Closed + Entrusted → 受托 Insert(EntrustedTaskId=原) → OnProcessDelegated
办结：TryCompleteAsDelegationReturn → 受托 Completed + 原 Waiting；节点不跳
```

| 规则 | 说明 |
|------|------|
| 禁止自委派 / 套娃 | `EntrustedTaskId` 非空不可再委派 |
| 目标已有打开待办 | 同活动已 Waiting → 拒绝 |
| SignIds/Names | **不刷新**（原人责任锚点） |

### 1.B 单流程定义 · 委托代批配置

#### 含义

只把「采购申请」交给张三代批，其它流程仍自己办——「我的委托」一行：`ProcessId=采购定义Id`（可再加时间窗，见 §2）。

#### 分层说明

| 步骤 | 归属 | 层 | 钩子/回调 | 宿主定义 | UseXxx |
|------|------|----|-----------|----------|--------|
| 配置 CRUD | **宿主** | Host API + 页 | — | `sf_surrogate`、`SailSurrogateService`、`WfSurrogateController`、`SailSurrogatePage` | 宿主 DI；表由 **`SailHostSchemaInitializer`**（PostBuild Feature） |
| 算人定范围 | **引擎** | Assignee 时刻 A：`IAssigneeResolver` | Resolve ConfigPair | 宿主可 `useAssigneeResolver` 覆盖 | **`UseBizAssignees`** + 可选 `UseSleveenOrgLookups` |
| 并入代理人 | **宿主实现 / 引擎槽位** | 时刻 A′：**Filter 链** order 50 | `SurrogateAssigneeFilter.Apply`（**不是** FlowHook） | `SurrogateMatchRules`（精确 ProcessId 优先） | Client：**`UseSleveenNodePolicyAssignee`** → `pipeline.AddFilter(new SurrogateAssigneeFilter(client), 50)` |
| 名单去重 | **引擎** Builtin | Filter order 60 | `DedupUsersFilter.Apply` | 宿主显式 AddFilter | 同上 UseXxx 内挂载 |
| 落库待办 | **引擎** | Mediator / `TaskManager` 建 Task | 普通 Created Notifier | 透传 `ProxySignId`/`Weight` | 引擎内建 |
| 会签结构 | **引擎** | `NodeMediator` SignTogether | — | — | 仅根席建子 AI；代理人扁平挂原人 AI |
| 完成条件 | **引擎** | 时刻 B Leave | `IActivityLeaveJudge` + `EffectiveWeightHelper` | Host 可选 EndText 本地化 Hook | Leave 随 `UseBizAssignees`；**无**代批专用 Use |

> **要点：** 代批**不**走 `DelegateProcess`，也**不**靠发送成功 Hook；唯一运行时挂钩是 Assignee **Filter.Apply**（建待办前）。

#### 作用域裁决（宿主纯函数）

```text
Grantor 行 → Enabled=1 且时间窗命中
  → ProcessId 精确匹配优先 → 否则 ProcessId 空（全部）
  → 同作用域取 UpdatedAt/CreatedAt 最新；判否不回退更旧行
```

#### 建任务效果

1. 只对**根席**（`ProxySignId` 空）查表。  
2. **追加**代理人，`ProxySignId=委托人`。  
3. 原人保留；只影响**新单**。

## 2. 第二部分 · 某个时间段临时委托

### 2.1 含义

时段委托的载体是 **委托代批配置**（不是办理条委派）。委派没有「周一到周五自动生效」——永远是点一下、管这一张。  
用 `StartAt` / `EndAt`（UTC）约束何时并人；可叠加 `ProcessId` 空（全部）或单定义。

| 产品意图 | ProcessId | StartAt / EndAt | Enabled |
|----------|-----------|-----------------|---------|
| 出差一周，全部流程 | 空 | 出差起止 | 1 |
| 出差一周，仅合同 | 合同 Id | 出差起止 | 1 |
| 长期代理某流程 | 某 Id | 空 | 1 |
| 暂停 | 任意 | 任意 | **0** |

### 2.2 分层说明

| 步骤 | 归属 | 层 | 钩子/回调 | 宿主定义 | UseXxx |
|------|------|----|-----------|----------|--------|
| 时间窗字段 | **宿主** | 产品表 | — | `sf_surrogate.start_at` / `end_at` / `enabled` | Schema Initializer |
| 窗内裁决 | **宿主** | Filter 内纯函数 | `SurrogateMatchRules.InWindow`（在 `Apply` 内调用） | — | 随 **`UseSleveenNodePolicyAssignee`** |
| 触发时机 | **引擎管道** | 仅 `TryResolveForTaskCreate` → Filters | **无**定时 Job 扫委托表；窗外自然不并人 | — | 同上 |
| 改窗/停用 | **宿主** | CRUD | — | Save / SetEnabled | API；**不**回调引擎改已建 Task |
| 与委派并存 | 正交 | 委派=命令层；代批=Filter 层 | 字段 `EntrustedTaskId` ⊥ `ProxySignId` | 办理条 + 我的委托 | Handler 包 + NodePolicyAssignee |

**生效时刻：** 只在建待办 Filter；已 Waiting 的代理待办不因改窗消失。

## 3. 第三部分 · 委托链

### 3.0 含义

两条链，禁止混谈：

| 链 | 产品 | 字段 | 深度语义 |
|----|------|------|----------|
| **委派回转链** | 办理条委派 | `EntrustedTaskId` | 强制深度 1；办结拆链还回 |
| **代批代理链** | 我的委托 | `ProxySignId` | Filter 不接力；Leave 可沿 Proxy 找根计权 |

### 3.1 委派回转链 · 分层说明

| 步骤 | 归属 | 层 | 钩子/回调 | 宿主 | UseXxx |
|------|------|----|-----------|------|--------|
| 建链 | 引擎 | `TaskManager.Delegate` | TaskLifecycle Entrusted | 触发来自 Handler | `AddSailOperationHandlers` |
| 持链 | 引擎 | `sf_task.EntrustedTaskId` | — | — | — |
| 禁套娃 | 引擎 | `TaskManager.Delegate` 校验 | — | — | — |
| 拆链回转 | 引擎 | Mediator 办结 → `TryCompleteAsDelegationReturn` | 办结路径内（非独立 EventFireType） | — | 引擎内建 |
| 命令级旁路 | 引擎槽 | 发起时 `OnProcessDelegated` | 产品可 `addHook` | 可选 | 默认 AfterSuccess |

```text
原 Task ──Delegate──► 受托.EntrustedTaskId
         ◄──办结回转──  链拆除，节点不推进
```

### 3.2 代批代理链 · 分层说明

| 步骤 | 归属 | 层 | 钩子/回调 | 宿主 | UseXxx |
|------|------|----|-----------|------|--------|
| 写 Proxy | 宿主 Filter | A′ Filter | `SurrogateAssigneeFilter.Apply` | 读 `sf_surrogate` | **`UseSleveenNodePolicyAssignee`** |
| 不接力 | 宿主 Filter | 同上 | 只扫 `ProxySignId` 为空的根 | — | 同上 |
| 落库 | 引擎 | Task 插入透传 | Created | — | 引擎 |
| 找根计权 | 引擎 | Leave | `EffectiveWeightHelper.GetWeightRoot` / `SumAgreedEffective` | LeaveJudge 禁止私自跟 Proxy | `UseBizAssignees` |
| 会签挂载 | 引擎 | `NodeMediator` | — | — | 代理人不新建子 AI |

```text
Resolve 根席 → Filter 追加 Agent(ProxySignId=根) → 落库
Leave：同根去重计权（李四+张三同意只计一次根权）
禁止：A→B、B→C ⇒ C 自动收到 A 的单（Filter 不接力）
```

### 3.3 两链对照（分层视角）

| 维度 | 委派回转链 | 代批代理链 |
|------|------------|------------|
| 主层 | Service/Action/Manager + 办结路径 | Assignee Filter + Leave |
| 钩子 | `OnProcessDelegated` + TaskLifecycle | **无**专用 FlowHook；Leave 回调 |
| 宿主必做 | Handler + 码表按钮 | 表 + CRUD + **`UseSleveenNodePolicyAssignee`** |
| 字段 | `EntrustedTaskId` | `ProxySignId` |

## 4. 数据与配置速查

### 4.1 `sf_surrogate`（宿主表）

| 列 | 说明 |
|----|------|
| `grantor_id` / `agent_id` | 委托人 / 代理人 |
| `process_id` | 空=全部；非空=单定义（§1.B） |
| `start_at` / `end_at` | 时段（§2）；UTC |
| `enabled` | 1 启用 |
| `weight` | 代理人票权（计权认根） |

### 4.2 UseXxx 清单（本专题相关）

| UseXxx | 阶段 | 本专题作用 |
|--------|------|------------|
| `UseBizAssignees()` | Builder | 管道 + Leave/Registry 骨架；**委派/代批共用前提** |
| `UseSleveenNodePolicyAssignee(configuration)` | Client Build 后 | **挂载** `SurrogateAssigneeFilter` + Dedup + NodePolicy 空人/同人 |
| `UseSleveenOrgLookups(configuration)` | Client | 组织 Resolver；代批不依赖，但常一起开 |
| `AddSailOperationHandlers()` | DI | **委派/转办**办理条 Handler |
| `UseNodePolicyAutoApproveHook()` | Builder | **不**参与代批；同人/空人入队 |
| `UseProcessExtraRuntime` | Builder | **不**参与代批；流程去重等 |
| `UseSleveenAssigneeAutoApproveJob` | 可选 | **勿**与 JobWorker 双开；与代批无关 |

### 4.3 引擎依赖面（无独立 Use）

| 项 | 位置 |
|----|------|
| `DelegateLane` / `FlowOperation.Delegate` | Actions/Assignee |
| `TaskManager.Delegate` / `TryCompleteAsDelegationReturn` | Manager |
| `Performer.ProxySignId` / `Weight` | Common |
| `EffectiveWeightHelper` | assignee Builtin |
| SignTogether 根席 vs 代理 Task | `NodeMediator` |

## 5. Leave 与「任一可办」

| 模式 | 行为 |
|------|------|
| `Race` | 任一方办结即可 |
| `Collaborate` + EffectiveWeight | 同根去重；非「两人各一票」 |
| 未改 Leave 只加人 | 易变双人会签——节点 Leave 须对齐预期 |

Leave 总表：[专题-多人办理模式.md](./专题-多人办理模式.md)。

分层：Leave = **引擎时刻 B**；配置在节点 `sf:leaveJudge`；实现随 `UseBizAssignees`。

## 6. 选型与验收

| 意图 | 用 |
|------|-----|
| 这一张请他代点，办完还我 | **委派**（§1.A） |
| 这一张交给他，我不办了 | **转办** |
| 仅采购流程、长期或带窗 | **代批** ProcessId=采购（§1.B / §2） |
| 下周全部流程 | **代批** ProcessId 空 + 时间窗（§2） |

| # | 期望要点 |
|---|----------|
| D1–D3 | 委派建链 / 禁套娃 / 回转不跳节点 |
| S1–S5 | 精确 ProcessId、不接力、窗外、改窗不影响旧单 |
| W1 | 会签代批同根去重 |

## 7. 红线

1. 禁止用 `DelegateProcess` 冒充出差代批。  
2. 禁止代批做成新 Resolve Type（必须 Filter）。  
3. 禁止 Filter 接力；禁止委派套娃 / 自委派自代批。  
4. 禁止办理条按钮名叫「委托代批」（配置进「我的委托」）。  
5. 遗留 `EntrustTask` 勿新产品化。  
6. `TaskNotifyKind.Entrusted` ≠ 产品「委派」专属。
