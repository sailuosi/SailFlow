## 0. 结论先行

| 项 | 口径 |
|----|------|
| **一句话** | 糖在 **`sailflow.biz`**：`ISailApprovalBusiness` + `AddApprovalBusiness` / `UseApprovalBusiness`；展开为 Registry + Sync Lifecycle Hook + Completing Gate |
| **解决什么** | **场景拼装成本**（FormBiz+Gate+Hook+Progress），不是再发明会签/退回/网关 |
| **路线** | **B1**：与 FormBiz **合并**（`ISailFormBizHandler : ISailApprovalBusiness`）；**不**进 pure/Mediator |
| **终态二分** | **到 End → `OnFinish(outcome)`**；**未到 End → `OnAborted(kind)`** |
| **失败** | **失败即失败**（抛错 FailFast）；**无**独立 `OnFailed`；糖层不承诺故障态+重试 |
| **强一致** | 终态回写须 **Sync + `ctx.Kit`**；禁止 Hook 内另开同库连接 |
| **宿主** | 实现 Handler + `UseXxx`；产品表/API 壳属宿主；引擎提供契约与默认展开 |
| **延后（非欠债）** | DefaultProcess 自举、采购宿主种子；样例在 `samples/external` |

```text
业务开发者维护一类
  PurchaseApprovalBusiness / LeaveFormBizHandler
    OnSubmit / OnStarted / OnCompleting / OnConsent / OnBackToModify
    OnFinish / OnAborted / OnQuery …

启动展开
  AddApprovalBusiness → Registry（FormCode 唯一）
  UseApprovalBusiness → Sync Hook（Finish/Aborted）+ Completing Gate
  宿主 FormBizHost / Dispatcher → Submit·Consent·Back（发起与办理旁路）
```

## 1. 契约与方法

### 1.1 含义

`FormCode` ≡ Runner **`BizChannel`**。同码重复登记 → **构建失败**。

| 方法 | 时机 | 典型职责 |
|------|------|----------|
| `OnInit` / `OnQuery` | 打开发起 / 回填 | 读业务表 |
| `OnSubmit` | 首次提交 | 插业务行；写出 **BizPK** / Conditions；Status=审批中 |
| `OnStarted` | Start 成功 | 回写 **ProcessInstanceId** |
| `OnCompleting(op, ctx)` | Gate 办理前 | Reject 拦下或抛错；同意前防篡改、转办校角色等 |
| `OnConsent` | 同意成功 | 可选进度文案；**不**写终态 |
| `OnBackToModify` | SendBack 成功 | 退回修改态（**非**终态） |
| `OnCancel` | Close/Reject… 办理旁路 | 可选中间态；终态仍以 Finish/Aborted 为准（须幂等） |
| `OnFinish` | **到达结束节点** | Outcome=`approved`/`rejected` → 终态 Status |
| `OnAborted` | **未到结束节点**终局 | kind=withdraw/discard/terminate/cancel/close… |

基类：`SailApprovalBusinessBase`（可空 override）。

### 1.2 分层说明

| 步骤 | 归属 | 层 | 钩子/回调 | 宿主定义 | UseXxx |
|------|------|----|-----------|----------|--------|
| 契约 | **sailflow.biz** | `ISailApprovalBusiness` | 上表 | FormCode | — |
| 登记 | biz / 宿主 | Registry | — | 一业务一类 | **`AddApprovalBusiness`** |
| 展开终态+Gate | biz | Sync Hook + Gate | Mapper → Finish/Aborted；白名单 → Completing | 按 BizChannel | **`UseApprovalBusiness`** |
| 发起壳 | **宿主** | `SailFormBizHost` 等 | Submit→Start→OnStarted | API | `AddSailFormBiz` |
| 办理旁路 | **宿主** | Dispatcher | NotifyAfterOperation → Consent/Back/Cancel | ButtonId | `AddSailOperationHandlers` |
| 列表进度 | biz.query | `QueryProgressByBizPKs` | — | BizChannel + BizPK[]（≤1000） | 宿主自滤权限 |

```csharp
builder
  .AddApprovalBusiness(_ => new PurchaseApprovalBusiness(store))
  .UseApprovalBusiness();

// 宿主请假等同构：
services.AddSailFormBiz();
builder.UseApprovalBusinessForHostFormBiz(); // 内部 Add + UseApprovalBusiness
```

## 2. 终态映射（落地）

### 2.1 含义

| 判据 | 回调 | 说明 |
|------|------|------|
| 实例因 **到达 End** 而终局 | **`OnFinish`** | Outcome 区分通过/驳回；**驳回结论仍是 Finish** |
| 实例 **未到 End** 即终局 | **`OnAborted`** | 撤回 / 作废 / 终止 / 关闭… |
| SendBack | **`OnBackToModify`** | 非终态 |
| 经引擎撤回 | **`OnAborted`** | **不**做「业务自撤跳过回调」特例 |

实现：`SailApprovalLifecycleMapper`（事件 + `ProcessState` 双读）。单测：`SailApprovalLifecycleMapperTests`。

### 2.2 分层说明

| 信号 | 门面 | 归属 |
|------|------|------|
| `OnProcessCompleted` / `ProcessState=Completed` | `OnFinish(approved)` | biz Hook |
| 驳回到 End（Completed） | `OnFinish(rejected)` | 同上 |
| Reject 仍 Running | 忽略 | 未办结 |
| Terminate / Closed / Canceled / Discarded | `OnAborted(...)` | 同上 |
| Withdraw + Running | 忽略 | 步骤撤回 ≠ 单据终态 |
| SendBack | 不进终态 Hook | Dispatcher → OnBackToModify |

细则与 Kit 红线见 [专题-业务状态回写.md](./专题-业务状态回写.md)。

## 3. 用法配方（采购故事 → 代码）

仿真键：`BizChannel`/`FormCode`=`purchase`；金额进 `Conditions["amount"]` 供网关（引擎不解释业务 Status）。

| 产品步骤 | 门面 | 引擎 |
|----------|------|------|
| 提交申请 | `OnSubmit` 落单 → Host Start → `OnStarted` | `StartProcess` |
| 主管同意 | `OnCompleting(Run)` 校验 → `OnConsent` | `RunProcess` + Leave/网关 |
| 退回修改 | `OnBackToModify` | `SendBackProcess` |
| 转办校角色 | `OnCompleting(Transfer)` | `TransferProcess` |
| 走到通过/驳回 End | `OnFinish` + **Kit** | 办结事件 |
| 撤回/作废 | `OnAborted` + **Kit** | Withdraw / Discard… |
| 我的申请列表 | `QueryProgressByBizPKs` | 实例/待办查询封装 |

样例（内存仓演示回调形状；生产须 Kit 写库）：

- `src/samples/external/src/Approval/PurchaseApprovalBusiness.cs`
- 宿主同构：`LeaveFormBizHandler` + `UseApprovalBusinessForHostFormBiz`

## 4. 硬约束

1. 禁止 Facade 改 NodeMediator；糖只在 **`sailflow.biz`**。  
2. 同一 FormCode **只登记一次**。  
3. `UseApprovalBusiness` **不可重复**；勿并行旧「三事件全进 OnFinish」Hook。  
4. OnFinish/OnAborted：**Sync + Kit**；Notifier/邮件不得进终态强一致路径。  
5. **失败即失败**；无 `OnFailed`；副作用归业务 Handler。  
6. Leave / Resolve / 抄送推送：**不**进门面。  
7. 经引擎的未到 End 终局 → **正常** `OnAborted`（业务勿先改终态再调引擎）。
