## 0. 一句话与划界

### 0.1 含义

**转办** = 我对**这一张**待办说：同事接手——**还停在当前节点**，原人待办关掉，对方开同活动新待办；对方办完按他自己推进，**不会**自动还给我。

| 口语 | Sail 码 | 是否本专题主角 |
|------|---------|----------------|
| 转办 / 交人 / 移交 | **`Transfer`** | ✅ |
| 委派（办完还回） | `Delegate` | ❌ 对照 → 委托代办专题 |
| 委托代批（配置并入） | Surrogate / `ProxySignId` | ❌ 对照 → 委托代办专题 |
| 改派（管理换全集） | `ChangeAssignee` | ❌ 对照 → 改签专题 |
| 减签 | `RemoveAssignee` | ❌ 对照：拿掉席位，不是交人 |
| 加签 | `SignForward` | ❌ 对照：临时插入审批拓扑 |
| 遗留 Entrust | `EntrustTask` | ❌ 勿新产品化；新代码走 Transfer / Delegate |

```text
我要换人办这件事？
 ├─ 这张单交出去，不办了、也不指望还回  → 本专题 Transfer
 ├─ 请他代点，办完必须还我               → Delegate
 ├─ 出差期间凡到我名下自动也能办         → Surrogate 委托代批
 ├─ 管理把当前节点人换成这批             → ChangeAssignee
 └─ 会签里拿掉某人 / 临时拉人先审        → RemoveAssignee / SignForward
```

### 0.2 分层说明（总览）

| 能力 | 归属 | 层 | 钩子/回调 | 宿主定义 | UseXxx |
|------|------|----|-----------|----------|--------|
| 办理条转办 | **宿主→引擎** | UX → Handler → Service | Gate=`Transfer`；成功 Hook=**`OnProcessTransferred`** | 码表 `Transfer`（默认开）；`TransferOperationHandler` | **`AddSailOperationHandlers`** |
| 写库交人 | **引擎** | Assignee `TransferLane` → `TaskManager.Transfer` | 路径内 `FireTaskLifecycle(Entrusted)` + 目标 `Created`；**不**在 Action 再抄 | EndType=`TransferredOut`；刷新 SignIds/Names | 引擎内建（A1） |
| 沟通硬锁 | **引擎** | `ConsultPendingGuard` | 拦截 Transfer（与 Run/Delegate 等） | Workbench `ConsultPending` | `UseBizAssignees` |
| 审计文案 | **宿主 Hook** | EndText 本地化 | 订任务结束类型 | `SailEndTextLocalizeHook`：`TransferredOut`→「已转办（不还回）」 | 宿主 Hook 装配 |


## 1. 执行链路

### 1.1 含义

待办人点「转办」→ 选至少一个接手人 → 引擎关己开人；活动仍 Ready/Running，**无** Runtime/Mediator 推进。

### 1.2 分层说明

| 步骤 | 归属 | 层 | 钩子/回调 | 宿主定义 | UseXxx |
|------|------|----|-----------|----------|--------|
| 显隐 | 宿主 | 节点 `sf:ButtonsSetting` ∧ 待办 `handle` | — | `SailButtonsCatalog.Transfer` Enable=true | 设计器可改名/关 |
| 选人提交 | 宿主 | `SailOperationBar` → `ButtonsOperation` | — | `NextActivityPerformers` 目标袋 | — |
| Handler | 宿主 | `TransferOperationHandler` | — | → `wf.TransferProcessAsync`；或 `POST …/TransferProcess` | **`AddSailOperationHandlers`** |
| 事务+锁 | **引擎** | `WorkflowService.RunAction` | — | 无独立 Forward 上下文 | — |
| Action | **引擎** | `TransferLane`（Assignee 族） | Gate=`FlowOperation.Transfer` | 校验 TaskId + 至少一个目标 | A1 骨架 |
| 沟通未清 | **引擎** | Guard（Execute 前） | `ConsultPendingGuard.TryAllow` | — | — |
| 写库 | **引擎** | `TaskManager.Transfer` | Lifecycle：原 `Entrusted`、新 `Created` | 见 §2 | — |
| 成功横切 | **引擎** | `AssigneeActionBase` | FlowHook **`OnProcessTransferred`** | 可旁路订 Hook | 默认管道 |

**不经** `WfRuntimeManager` / `NodeMediator`——与委派同属 Assignee「不推进」族。

## 2. 写库与规则

### 2.1 含义

原人待办 **Closed**（勿用 Completed，避免会签计为已办）+ EndType **`TransferredOut`**；目标同 `ActivityInstanceId` **Insert** 新待办；按仍打开待办 **刷新** `SignIds`/`SignNames`（转出人不再占会签未办名额）。

```text
校验：本人 Waiting/Reading · AI Ready/Running · 有目标 · 非自己 · 目标无打开待办
  → 原 ApplyTaskEnd(Closed, TransferredOut) + Fire(Entrusted)
  → 逐目标 Insert 同活动新待办 + Fire(Created)
  → RefreshActivitySignFromOpenTasks
  → OnProcessTransferred
对方再 Approve/Run → 正常办结推进（产品口径：不回转）
```

### 2.2 分层说明

| 规则 | 归属 | 层 | 说明 |
|------|------|----|------|
| 仅本人待办 | 引擎 | Manager | `task.SignId == runner.UserId`；否则 `Transfer_NotMineTask` |
| 待办态 | 引擎 | Manager | 仅 Waiting / Reading |
| 活动态 | 引擎 | Manager | 仅 Ready / Running |
| 禁止自转 | 引擎 | Manager | 目标 UserId ≠ 本人 |
| 目标已有打开待办 | 引擎 | Manager | 同活动已 Waiting/Reading → 拒绝 |
| 多目标 | 引擎 | Action 展平 | `NextActivityPerformers` 各袋合并；可多人接手 |
| Sign 刷新 | 引擎 | Manager | **刷新**（≠ Delegate 不刷新） |
| 会签名额 | 引擎 | Sign 刷新 | 转出人不再占用未办名额（缺口 §F） |

### 2.3 实现注意（`EntrustedTaskId`）

| 项 | 产品口径 | 代码现状 |
|----|----------|----------|
| 办结是否还回 | **不还回**；对方推进 | `Transfer` 的 `Insert` **仍传入**原 `taskId` 写入 `EntrustedTaskId`；办结侧 `TryCompleteAsDelegationReturn` **仅凭该字段**判断回转 |
| 通知 Kind | 交人通知 | 路径内复用 `TaskNotifyKind.Entrusted`（与委派发起同 Kind）；审计结束类型用 **`TransferredOut`** 区分；推送细表见 [专题-待办推送.md](./专题-待办推送.md) §4.3 |
| 专题立场 | 对外语义以「不还回」为准 | 若联调出现「转办后同意却回到原人」，属实现债：Transfer **不应**写回转链，或回转路径须排除 `TransferredOut` 来源 |

委派专题靠 `EntrustedTaskId` 回转链；转办产品语义**不靠**该链——二者勿在文案上混成「都挂了就都是委托」。

## 3. 与邻域对照

| 维度 | 转办 `Transfer` | 委派 `Delegate` | 改派 `ChangeAssignee` | 减签 `RemoveAssignee` |
|------|-----------------|-----------------|------------------------|------------------------|
| 触发 | 办理人交**自己的**待办 | 办理人请人代办 | 有权人改**全集** | 拿掉未办人 |
| 原人 | Closed + `TransferredOut` | Closed + `DelegatedOut` | 不在新集合则 Removed | Removed |
| SignIds | **刷新**为打开集合 | **不刷新** | 刷新 | 刷新 |
| 对方办结 | **推进**（产品） | **回转原人**、不推进 | — | — |
| 回转字段 | 产品不依赖 | **必须** `EntrustedTaskId` | — | — |
| 默认码表 | **开** | 关 | 关 | 视节点 |

| 说法 | 别当成 | 正确锚点 |
|------|--------|----------|
| 转办 | 委派 | 不还回 vs 办完还回 |
| 转办 | 委托代批 | 单笔实例交人 vs 配置建任务并入 |
| 转办 | 改派 | 交自己的待办 vs 管理换全集 |
| 转办 | 加签 | 不改 SignForward 拓扑，只换 Task |
| 转办 | 节点流转 | **不发生**下一跳 |

## 6. 红线

1. **转办 ≠ 委派**：办完要还回必须用 Delegate；码表勿把二者合成一个「委托」按钮。  
2. **转办 ≠ 节点跳转**：禁止用 Transfer 冒充 Jump/Run。  
3. **原人用 Closed + TransferredOut**，禁止 Completed（会签计票）。  
4. **Leave 正交**：转办不得默认可绕过 Collaborate / 抢办。  
5. **沟通未清**时 Transfer 与 Run 等一并拦截。  
6. 遗留 `EntrustTask` **勿**新产品化。  
7. 审计文案以 EndType=`TransferredOut` 为准，勿仅凭 Lifecycle Kind=`Entrusted` 显示成「委派」。
