## 0. 一句话与划界

### 0.1 含义

**退回** = 办理人把流程**打回到可选历史节点**，被退回人改完后再提交；产品用**两维正交配置**约束「能退到哪」与「改完怎么走」，**不是**单一五选一枚举。

| 口语 | Sail 码 | 是否本专题主角 |
|------|---------|----------------|
| 退回 / 打回 / 回退 | **`SendBack`** | ✅ 主角（维①执行） |
| 返送退回人 | **`Resend`** | ✅ 维②=`ReturnToSender` 时的再发送 |
| 改完正常往下走 | **`Run` / `Approve`** | ✅ 维②=`ForwardNormal` 时的再发送 |
| 驳回 / 拒绝 | `Reject` | ❌ 对照：设计期落点、**不**写 BackSrc、**不**走两维 UX |
| 撤回 | `Withdraw` | ❌ 对照：已办人撤回；同 Runtime 壳、语义不同 |
| 反转 | `Reverse` | ❌ 对照：≠ SendBack |

```text
SendBack（维①：退到哪）
    → 落点节点带 BackSrc（指向退回来源活动）
被退回人再发送（维②）
    ├─ ReturnToSender → ResendProcess（回退回节点 / 原退回人）
    └─ ForwardNormal  → Run/Approve（沿下一跳）
```

### 0.2 分层说明（总览）

| 能力 | 归属 | 层 | 钩子/回调 | 宿主定义 | UseXxx |
|------|------|----|-----------|----------|--------|
| 两维配置 | **宿主** | 设计器 / Extra | — | NodePolicy `sendBackTarget`×`resubmitMode`；Extra 非空覆盖节点 | 无专用 Use；落盘 BPMN/`sf_process_meta` |
| 策略合并 + 列表收窄 | **宿主** | Workbench API | — | `SailSendBackPolicy.Resolve`；`FilterPreviousBySendBackTarget` → `PreviousNodes` | 办理台加载路径（`Wf2Xml` Workbench） |
| 办理条退回 | **宿主→引擎** | Handler → Service | Gate=`SendBack`；成功 Hook=**`OnProcessSendBacked`** | `SendBackOperationHandler`（校验目标 ActivityId） | **`AddSailOperationHandlers`** |
| 退回写库 | **引擎** | Transition `SendBackAction` → `WfRuntimeManagerSendBack` → `NodeSendBack*` | 路径内 TaskLifecycle Cancelled/Created；命令级 AfterSuccess 仅族群 Hook | — | 引擎内建（A3） |
| BackSrc 落库 | **引擎** | AI / Mediator 回跳 | — | 列 `BackSrcActInstanceId`；Workbench 读出 `HasBackSrc` | 引擎内建 |
| 返送 | **宿主→引擎** | `ResendOperationHandler` → `ResendAction` | Gate=`Resend`；Hook=**`OnProcessResent`** | 详情页按 `HasBackSrc`+`resubmitMode` 互斥露出 | **`AddSailOperationHandlers`** |
| 正常再发送 | **宿主→引擎** | Approve/Run Handler → `RunAction` | Gate=`Run`；Hook=**`OnProcessContinued`**（Resent 不走此） | 互斥：有 BackSrc 且 ReturnToSender 时默认藏「通过」 | 同上 |
| 同人/去重自动过 | **宿主 Hook** | FlowHook | **不订阅** `OnProcessSendBacked` | — | `UseNodePolicyAutoApproveHook` / `UseProcessExtraRuntime`（边界：退回后不自动回来） |

```csharp
// 退回命令本身无独立 UseXxx；依赖：
.UseBizAssignees()                 // ConsultPendingGuard 等与其它办理共用
// Build 后 / DI：
services.AddSailOperationHandlers(); // SendBack / Resend / Reject / Approve…
// 同人自动过（刻意不订 SendBacked）：
.UseNodePolicyAutoApproveHook()
.UseProcessExtraRuntime(sp)
```

## 1. 两维策略（配置要素）

### 1.1 含义

| 维度 | 问什么 | 码 | 默认 |
|------|--------|-----|------|
| **① `sendBackTarget`** | 可以退到哪个节点 | `Prev` / `Starter` / `History` | `Starter` |
| **② `resubmitMode`** | 被退回人改完后再送 | `ForwardNormal` / `ReturnToSender` | `ReturnToSender` |

合并规则（宿主）：**Extra 非空覆盖节点**对应维（`SailSendBackPolicy.Resolve`）。

| 维① | Workbench `PreviousNodes` |
|-----|---------------------------|
| `Prev` | 仅上一节点（列表 Take 1） |
| `Starter` | 发起节点（无则退列表末） |
| `History` | 完整可退历史 |

| 维② | 再发送按钮 |
|-----|------------|
| `ReturnToSender` | 有 `HasBackSrc` 时突出 **返送**（`Resend`）；默认收紧「通过」 |
| `ForwardNormal` | 有 BackSrc 时走 **正常发送**（Approve/Run）；默认不露 Resend |

### 1.2 分层说明

| 步骤 | 归属 | 层 | 钩子/回调 | 宿主定义 | UseXxx |
|------|------|----|-----------|----------|--------|
| 节点两维 UI | 宿主 | 设计器 | — | `SailNodeConfigPanel`「退回策略」 | — |
| 流程级覆盖 UI | 宿主 | Extra 更多设置 | — | `ExtraSettings` → `extra_json.sendBackTarget/resubmitMode` | `UseProcessExtraRuntime` 只消费其它 Extra；**退回两维由 Workbench 读** |
| 解析 NodePolicy | 宿主 | Utility | — | `SailNodePolicyCatalog` | — |
| 合并 Extra | 宿主 | Utility | — | `SailSendBackPolicy` | — |
| 下发办理台 | 宿主 | Workbench DTO | — | `ApprovalWorkbenchDto.SendBackTarget/ResubmitMode/PreviousNodes/HasBackSrc/BackSrc*` | Controller 组装 |

## 2. 执行退回 · `SendBack`

### 2.1 含义

当前待办人选择**允许范围内的目标节点**（及办理人袋），调用 `SendBackProcess`：取消/办结当前侧，在目标活动重建待办，并留下 **BackSrc** 供日后返送。

### 2.2 分层说明

| 步骤 | 归属 | 层 | 钩子/回调 | 宿主定义 | UseXxx |
|------|------|----|-----------|----------|--------|
| 点「退回」 | 宿主 | UX | — | `SailOperationBar` 弹窗选 `PreviousNodes` | 码表 `SendBack` 启用 |
| Handler 校验 | 宿主 | OperationHandler | — | 无目标 → `SendBackTargetMissing` | **`AddSailOperationHandlers`** |
| 事务+锁+Action | **引擎** | `RunAction` → `SendBackAction` | Gate：`FlowOperation.SendBack`；成功：**`OnProcessSendBacked`** | — | 引擎 Transition 族 |
| 沟通未清 | **引擎** | Transition `Execute` 前 | `ConsultPendingGuard` | — | 引擎 |
| Factory | **引擎** | `CreateRuntimeInstanceSendBack` | — | 读 Running、校验本人待办、Previous 列表等 | 引擎 |
| Runtime | **引擎** | `WfRuntimeManagerSendBack.ExecuteInstanceImp` | — | — | 引擎 |
| 节点执行 | **引擎** | `NodeSendBack*`（Task / MIS…） | 路径内 Cancelled（当前）+ Created（落点） | — | 引擎 |
| 收尾 | **引擎** | `TaskManager.SendBack` · `ActivityInstanceManager.SendBack` | 写 BackSrc 等回跳信息 | — | 引擎 |

```text
ButtonsOperation(SendBack)
  → SendBackOperationHandler（目标非空）
  → SendBackProcess → SendBackAction
       → CreateRuntimeInstanceSendBack
       → Gate(SendBack) → Runtime.Execute → NodeSendBack*
       → OnProcessSendBacked
```

### 2.3 与撤回 / 驳回（对照分层）

| | 退回 SendBack | 撤回 Withdraw | 驳回 Reject |
|--|---------------|---------------|-------------|
| 谁点 | 当前待办人 | 通常已办人 | 当前待办人 |
| 目标 | 运行时可选（受维①） | Factory 定位运行节点 | **设计期** RejectMode，人取历史 |
| BackSrc / Resend | **有** | 同壳可写回跳，产品不当两维退回 | **无** BackSrc/Resend 语义 |
| Hook | `OnProcessSendBacked` | `OnProcessWithdrawn` | `OnProcessRejected` 或 Terminate 事件 |
| Host Handler | `SendBackOperationHandler` | Withdraw Handler | `RejectOperationHandler` → **只** `RejectProcess` |

**红线：** Specified 驳回**禁止**再转调 `SendBackProcess`（现行 Handler 已遵守）。

## 3. 再发送 · 维②

### 3.1 含义

落点节点上的办理人改完表单后：

- **返送**：回到打回自己的那个节点（尽量原退回人）→ `ResendProcess`。  
- **正常发送**：按流转条件走下一跳 → `Run`/`Approve`。

依赖当前活动实例 **`BackSrcActInstanceId`**：Workbench 译为 `HasBackSrc` + `BackSrcUserId/Name`（取自 BackSrc 活动的 **`EndedUser*`**，禁止用 CreatedUser*）。

### 3.2 分层说明 · 返送 `Resend`

| 步骤 | 归属 | 层 | 钩子/回调 | 宿主 | UseXxx |
|------|------|----|-----------|------|--------|
| 按钮露出 | 宿主 | 详情 UX | — | `hasBackSrc && resubmitMode===ReturnToSender`（管理例外另议） | — |
| Handler | 宿主 | OperationHandler | — | `ResendOperationHandler` | **`AddSailOperationHandlers`** |
| Action | **引擎** | `ResendAction` | Gate=`Resend`；Hook=**`OnProcessResent`** | — | Transition 族 |
| Factory | **引擎** | `CreateRuntimeInstanceResend` | 读当前 AI + BackSrc AI | — | 引擎 |
| Runtime | **引擎** | `WfRuntimeManagerResend` | Mediator 强制指向退回源（`isNotParsedByTransition`） | — | 引擎 |

### 3.3 分层说明 · 正常发送 `Run`

| 步骤 | 归属 | 层 | 钩子/回调 | 宿主 | UseXxx |
|------|------|----|-----------|------|--------|
| 按钮露出 | 宿主 | UX | — | 有 BackSrc 时：仅 `ForwardNormal` 默认露「通过」 | — |
| 执行 | 宿主→引擎 | Approve/Run Handler → `RunAction` | Gate=`Run`；Hook=`OnProcessContinued` | — | Handlers + 引擎 |
| 与 Resend 互斥 | 宿主 | UX 策略 | — | `SailProcessDetailPage` 按两维收紧 | — |

### 3.4 自动过边界（再发送后）

| 步骤 | 归属 | 层 | 钩子 | 说明 |
|------|------|----|------|------|
| 入队 | 宿主 | FlowHook | **仅** Started / Continued / **Resent** | 返送成功会订 `OnProcessResent` → 可能再次触发同人/去重入队 |
| 退回当下 | 宿主 | FlowHook | **不订** `OnProcessSendBacked` | 退回落点**不会**因同人策略自动回来 |

## 4. BackSrc 与数据面

### 4.1 含义

`ActivityInstance.BackSrcActInstanceId`：当前活动「是被哪次退回来源活动打回来的」。有值 ⇒ 可 Resend；返送/部分前进路径会传递或清理该信息（见 Mediator `WriteBackSrcOrgInformation` 等）。

### 4.2 分层说明

| 步骤 | 归属 | 层 | 钩子 | 宿主 | UseXxx |
|------|------|----|------|------|--------|
| 写入 | **引擎** | SendBack / 回跳写库 | — | — | 引擎 |
| 读取办理台 | 宿主 | Workbench | — | `HasBackSrc`、`BackSrcActInstanceId`、`BackSrcUserId/Name` | Controller |
| 驳回路径 | **引擎** | Reject 回跳 | — | **不**按退回两维写 Resend 语义 | — |

## 5. 产品配置落点

| 配置 | 位置 | 默认 |
|------|------|------|
| `sendBackTarget` | 节点 `sf:NodePolicy.json` | `Starter` |
| `resubmitMode` | 同上 | `ReturnToSender` |
| 流程级覆盖 | ExtraJson 同名字段 | 空=节点优先 |
| 驳回（对照） | `rejectHandlerType` + `returnNodeId` | Previous(3)；**≠** 退回两维 |

设计器文案：退回两维与「审批人拒绝时」分属两张卡片——**退回可选手动目标；驳回不选目标/人**。

## 6. UseXxx / 装配清单

| 项 | 本专题作用 |
|----|------------|
| **`AddSailOperationHandlers`** | 注册 SendBack / Resend / Reject / Approve… |
| `UseBizAssignees` | 管道；Consult 硬锁等 |
| `UseNodePolicyAutoApproveHook` | **不**订 SendBacked；订 Continued/Resent |
| `UseProcessExtraRuntime` | Extra 其它字段；退回两维由 Workbench 读 Extra，非此 Hook 执行退回 |
| （无）`UseSendBack*` | **不存在**——退回是一等 Transition 命令 |

引擎侧：`SendBackAction` / `ResendAction` / `RejectAction` / `WithdrawAction` 均已纳入 Transition 动作骨架，无需宿主再挂 Action。

## 7. 选型与验收

| 意图 | 用 |
|------|-----|
| 打回上一节点 / 发起人 / 自选历史，且允许改完返送 | SendBack + 维① + 维②=`ReturnToSender` |
| 打回后改完按流程继续 | SendBack + 维②=`ForwardNormal` |
| 办理人一键拒绝到固定落点、不要返送语义 | **Reject**（RejectMode） |
| 我已办完想撤回 | **Withdraw** |

| # | 期望 |
|---|------|
| G1 | 维①=Prev 时 PreviousNodes 仅 1 个 |
| G2 | SendBack 无目标 → `SendBackTargetMissing` |

| J1 | ReturnToSender：露返送、默认收紧通过 |

## 8. 红线

1. 退回两维 **不要**压成 AntFlow 式单一五码主键（五码仅对照别名）。  
2. **驳回 ≠ 退回**：Reject 不开放 History 自选、不写 Resend 链；禁止 Specified 转调 SendBack。  
3. **撤回 ≠ 退回**：勿在产品文案混用。  
4. BackSrc 退回人取 **EndedUser***，禁止 CreatedUser*。  
5. 同人/去重自动过 **不订** `OnProcessSendBacked`；退回落点须人办或再次正向/返送。  
6. 沟通未清时 SendBack 与 Run 等一并被 `ConsultPendingGuard` 拦截。
