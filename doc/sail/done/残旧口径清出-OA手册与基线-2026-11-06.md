## 1. OA 手册 · `_wfAppRunner` 样例（原 §6.3）

```csharp
public async Task<WfExecutedResult> RunProcessAsync(WfAppRunner runner, CancellationToken cancellationToken = default)
{
    _wfAppRunner = runner;   // ❌ H 不得扣 B；D3 已去掉字段
    using (var kit = Sail.UseRunSQL())
    {
        kit.beginTransaction();
        var result = await RunAsync(kit, cancellationToken);
        if (result.Status == WfExecutedStatus.Success)
            kit.commit();
        return result;
    }
}
```

**现行**：`CommitOnSuccessAsync(kit => RunAsync(kit, runner, cancellationToken))`；Service 无 Runner 字段。
