## A 空人 / 同人 / 超时

| # | 场景 | 期望 |
|---|------|------|
| A1 | 节点默认空人 + Resolve 无人 | 推进失败，`ReasonCode=AssigneeEmpty` |
| A2 | 空人=3 + 指定账号 | 待办落指定人 |
| A3 | 空人=4 + 已配 ProcessAdminUserIds | 待办落管理员 |
| A4 | 空人=4 + 未配管理员 | `ProcessAdminNotConfigured` |
| A5 | 空人=1 | 出现 `__sail_policy_skip__` 待办 → 数秒内被作业办结 |
| A6 | 同人=2 且办理人=发起人 | 同上跳过代办 |
| A7 | 超时启用 + 短时长 + Type=2 | Overdue 后自动同意 |
| A8 | 超时 Type=3 | Overdue 后 Reject |
| A9 | 超时 Type=1 | 日志/Notifier 提醒，不超过 maxRemindCount（按任务计数） |
| A10 | approveType=2/3 | 自动通过 / 自动拒绝（策略账号 + 作业） |
| A11 | Reject + rejectHandlerType=2 + returnNodeId | 走退回指定节点，非整单结束 |
| A12 | 会签多待办先后产生 | 后产生的子待办按自身创建时间计超时，互不抢先 |
