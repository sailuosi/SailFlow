# 专题附录 · 范围（Scope）注册清单与抄送圈人分流

> 隶属：[专题-对象解析器.md](./专题-对象解析器.md) **A6**  
> 口径：Type = Scope 注册键；Mode=`selectModel` 外挂。引擎不塞宿主 HR schema（R3）。

---

## 1. 内置 Scope（pure `RegisterBuiltins`）

| 码 | 包/类 | 说明 | 可覆盖 |
|----|-------|------|--------|
| `AnyMan` | `AnyManAssigneeResolver` | 空约束；配合 Pick 选人器不限范围 | ✅ |
| `Specific` | `SpecificAssigneeResolver` | 调用方显式传入 | ✅ |
| `FixedUsers` | `FixedUsersAssigneeResolver` | Params.userIds | ✅ |
| `RoleGroup` | `RoleGroupAssigneeResolver` | Params.roleIds；默认骨架，宿主常覆盖 | ✅ 宜覆盖 |
| `ProcessRelative` | `ProcessRelativeAssigneeResolver` | 发起人/上一办等 | ✅ |
| `UnitMap` | `UnitMapAssigneeResolver` | Params.unitField + maps | ✅ 宜覆盖 |
| `JobRelative` | `JobRelativeAssigneeResolver` | Params.jobCode / maps | ✅ 宜覆盖 |
| `Expression` | `ExpressionAssigneeResolver` | Conditions 表达式 | ✅ |
| `BusinessCallback` | `BusinessCallbackAssigneeResolver` | Params.callback | ✅ |
| `Fallback` | `FallbackAssigneeResolver` | 空人链式回落 | ✅ |

**非 Scope（勿作新图 type）：**

| 码 | 状态 |
|----|------|
| `ApproverPick` / `StarterPick` | 旧模式码；新图用 `selectModel=Pick` / `Preselect+Start` |
| `Preselect` | **Store 解析器槽**（`UsePreselectAssignees`），不是人员 Scope |

## 2. 宿主外置 Scope（bidaibuddy / Sleveen）

| 码 | 注册点 | 说明 |
|----|--------|------|
| `RoleGroup` | `SleveenRoleGroupAssigneeResolver` | 覆盖：VisitorBag / Duty |
| `UnitMap` | `SleveenUnitMapAssigneeResolver` | 覆盖：Org/User |
| `JobRelative` | `SleveenJobRelativeAssigneeResolver` | 覆盖：maps / 访客袋 |
| `deptBoss` | `DeptBossAssigneeResolver` | **部门领导**；`Sail:DeptLeaderRoleIds` |
| `DeptMembers` | `DeptMembersAssigneeResolver` | **部门所有人**；Params.orgId 空=发起人管理组织；≠ deptBoss |

挂载入口：`UseSleveenOrgLookups` → `UseSleveenPreselectAssignees` → `UseSleveenNodePolicyAssignee`。

## 3. Pick 落库 / Preselect 仓（非 Scope）

| 能力 | 接口 | 默认 |

## 4. 抄送圈人 API 分流（R5）

| 路径 | 用途 | 禁止 |
|------|------|------|
| **办理取人** | `AssigneePipeline.TryResolve*` → `PerformerList` → 建待办 / 动词 | 抄送人写入 SignIds / NextActivityPerformers |
| **抄送提交** | `WfCopyto/Create`（`SailProcessCopyto`）；Targets 显式用户列表 | 走办理管道当「下一办理人」 |
| **圈人候选（共用）** | 选人器 / Resource 预览（如角色预览 `PreviewUsersByRoleIds`、HostUserSearch） | 把预览结果直接当已建待办 |

```text
抄送 UX
  → 选人器可按 Scope 码调「圈人预览 API」（与 Fixed Scope.Resolve 同源思路）
  → 用户确认后 POST WfCopyto/Create { Targets: [...] }
  → 不调用 TryResolveForTaskCreate / 不写 Performer[]
```

办理条 `Copyto` 按钮 `engine=WfCopyto/Create`，与 Approve/Transfer 分流。
