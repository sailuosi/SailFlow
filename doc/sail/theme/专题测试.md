## 4. 回归锚点

| 锚点 | 为何 |
|------|------|
| 前加签后本人待办不可先开 / 打开无 NRE | 曾：容器 `CompleteOrder` 误判 MI → `PreviousStepChecker` NRE |
| 后加签本人通过不直接出节点 | Waiting 唤醒加签人；勿子帧即 ContinueForward |
| 加签不改节点 `ai_leave_*` | 席位级契约；子规则写发起人容器 |
| 沟通未清时 Run/退回/转办等硬锁 | ConsultPending |
| **并加签一人即出 / 发起人通过报「无匹配后续节点」** | 曾：宿主硬编码 `count/1` → 容器 Count 阈=1；`IsLastTask` 未计发起人直属 Task。修：宿主只传子型；引擎 Parallel 强制 Percentage=1；并行末席计入发起人打开待办 → **S10 初测 ✅** |
| **转办目标已有待办提示英文 / 拒绝前已关原待办** | 曾：硬编码英文；校验在 `ApplyTaskEnd` 之后。修：`GetEngineMessage` + zh/en；校验前置 → **T3 / S14–S15 ✅** |
| **嵌套子流程结束报「办结无角色人员」** | 曾：`FillNextActivityPerformersByRoleList` 只认 Roles，ApproverPick 空角色即 throw。修：`SubProcessMainContinueHelper` 空角色回落办结人 → **S21 ✅** |
| **嵌套子流程结束报「子流程未到结束状态」** | 曾：续推无 TaskId + `CheckSubProcessInstanceCompleted` 要求 Count==1。修：传 `sail.completedSubProcessInstanceId` 确定性校验；Check `Count>=1` → **S21 ✅** |
| **发送报「未知的多实例节点类型」** | 曾：设计器无条件写 `MultiSignDetail`（`complexType=0`）→ ConvertHelper 升格 MultiSignNode → CreateNodeMediator 291。修：仅有效 complexType 升格；不启用则删除扩展 → **S22 ✅**；网关/条件加签退回 **S23/S24 ✅** |
| **Collaborate+加签误显下一节点** | 曾：`IsLastTaskSignForwardSeat` 外层非 Race 只扫兄弟子 AI，扁平旁人仍挂节点 AI → 误 Last。修：`HasOpenPeerApproverTasksOnParent` → **S26 / C2 ✅** |
| **ForwardNormal 仍只出返送** | 曾：XML 已是 ForwardNormal，XPath `local-name()='NodePolicy'` 匹配不到 bpmn-js 的 `sf:nodePolicy` → 回落默认 ReturnToSender。修：兼认 camelCase + Regex 回落 → **S28 / T4 ✅** |
| **改派已启用但办理条不显示** | 曾：详情 `loadProcessAssets` 用 `ButtonsSetting` 精确匹配覆盖 Workbench → 回落默认关。修：FE `parseButtonsSetting` 忽略大小写 + Regex → **S29 / CA1 ✅** |
