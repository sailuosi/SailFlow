# 专题 · 节点实例临时子规则

> 状态：**已落地**（2026-11-21：AI Leave 快照 + 加签改写子 Leave + MultiSignForward 统一 `TryCanLeave`）  
> 用途：把 **加签（`SignForward`）** 收成「真实节点上的**临时审批子堆栈**」：子规则落在主 AI 的 **Leave 快照**；存续期内 **AI Leave 即生效规则**；**Passed → 塌缩主容器并 ContinueForward**。回答「Leave 与加签如何叠」「抢办上后加签为何能生效」。  
> 范围：运行时语义与落库；不含加批拆命令、不含独立 `Sequence` LeaveJudge 码。  
> 宿主：`SailOperationBar` 前/后/并加签；串行不加 count/1。库表需 upsert 补列 `ai_leave_type` / `ai_leave_params`。

## 0. 结论先行

| 项 | 口径 |
|----|------|
| **AI Leave 快照** | `ai_leave_type` / `ai_leave_params`；建实例时从设计 `sf:leaveJudge` 拷贝 |
| **读取优先级** | **AI 非空 > BPMN 设计 > Legacy 推断**（`BpmnAssigneeConfigReader.ReadLeave`） |
| **外层（设计）** | BPMN `sf:leaveJudge`（Race / Collaborate …）；写入新 AI 快照，**不因加签改 BPMN** |
| **内层（临时子堆栈）** | `SignForward` 升级主 AI：`ComplexType=SignForward` + **改写**主 AI Leave 为子规则 |
| **子规则落库** | 前/后：`LeaveJudgeType=Collaborate` + `MergeType=Sequence` + `CompleteOrder=席位数`；并：`Collaborate` + `Parallel` + Percentage 全员 |
| **子规则 Passed** | 塌缩主容器（完结主 AI、取消未完成子）并 **ContinueForward**（存续期内不再二次问设计 Leave） |
| **「剩 1 人」≠ 塌缩** | 后加签本人办完只剩加签人时 Waiting，须唤醒加签人；达阈才 Passed |
| **抢办 + 后加签** | 加签后主 AI Leave 改为 Collaborate/Sequence，挡住中途 Race；全员过完才出节点 |
| **抢办 + 并加签** | 主 AI Leave 改为 Collaborate/Parallel 全员；勿用 count=1 |

```text
建 AI：设计 Leave → ai_leave_type（快照）
SignForward：改写主 AI Leave = Collaborate + Merge（子堆栈）
办结子席 → TryCanLeave（优先读 AI）
  Waiting + Sequence → 唤醒下一挂起子
  Passed             → 塌缩主 AI → ContinueForward
```

## 1. 两层帧模型

### 1.1 含义

把一次用户任务上的审批看成**帧栈**：

| 帧 | 何时存在 | 规则落点 | 规则成功的结果 |
|----|----------|----------|----------------|
| **节点帧（无加签）** | 令牌落在该活动 | AI 快照 = 设计 Leave | `TryCanLeave` Passed → 出节点 |
| **加签子堆栈** | `SignForward` 之后、主 AI 完结前 | 主 AI **改写**为子 Leave（Collaborate + Merge） | Passed → **塌缩并 ContinueForward** |

- **Leave** 仍只回答「怎样才算离开当前帧」——不负责建图。  
- **SignForward** 负责建临时图（主+子 AI），并把主 AI Leave **改写**为子规则。  
- **正交**：BPMN 设计侧 `sf:leaveJudge` **不改**；改的是实例快照。读取时 **AI 非空优先于设计**。  
- **落地口径**：加签存续期内**不再二次问设计 Leave**；子规则达阈即视为本节点可出（对原 Race 节点 =「把关完再走」）。

### 1.2 与结构 B 的关系

落库仍是 [专题-节点实例与任务.md](./专题-节点实例与任务.md) 的结构 B：

```text
原当前 AI ──升级──► 主 AI（Suspended, ComplexType=SignForward）  ← 子堆栈容器
                      ├─ 子 AI（本人）→ Task
                      └─ 子 AI（加签人…）→ Task
```

| 子型 | 入栈节奏 | 主 AI 子 Leave |
|------|----------|----------------|
| **前加签** Before | 加签人先 Ready；本人子常先 Suspended | `Collaborate` + Sequence + Count=席位数 |
| **后加签** Behind | 本人先；加签人子先 Suspended | 同上 |
| **并加签** Parallel | 本人与加签人并行（子 `CompleteOrder` 常 -1） | `Collaborate` + Parallel + Percentage=1（全员） |

前/后差别是**建栈顺序与谁先 Ready**；出栈都走同一 `Collaborate` LeaveJudge，靠 `MergeType` 区分串/并。**不**新增独立 `Sequence` Leave 码。

### 1.3 办结路径（语义）

```text
办结当前子 AI / Task
  → TryCanLeave（主 AI.LeaveJudgeType 优先）
      Waiting + Sequence → Ready 下一挂起子；不出节点
      Waiting + Parallel → 继续等；不出节点
      Passed / NotPassed → 塌缩主 AI → ContinueForward
```

无加签时：AI 快照即设计 Leave，普通 / 会签路径同样走管道。

## 2. 子规则口径

### 2.1 什么算子规则 Passed

| 子型 | Passed 条件（语义） | 非 Passed 时 |
|------|---------------------|--------------|
| 前 / 后（Sequence） | 当前子为串行**末席**且本席办结（同意路径达阈） | `CompleteOrder < maxOrder` → Ready 下一挂起子；**不出节点** |
| 并（Collaborate-like） | 子席完成度达到并签阈值（人数或比例） | WaitingForCompletedMore；**不出节点** |

### 2.2 禁止的误判

| 误判 | 为何错 |
|------|--------|
| 「打开/挂起席位只剩 1 人」→ 出节点 | 后加签本人办完后常剩加签人 1 席，Leave 仍 Waiting，须唤醒加签人 |
| 串行主 AI 写 `Count + CompleteOrder=1` | 本人被当成末人 → 取消加签人并出节点（SF2 失败；引擎已禁写） |
| 加签后仍按设计 Race 中途出节点 | 主 AI Leave 已改写为 Collaborate；须读 AI 快照 |

### 2.3 现行实现对照（已落地）

子规则 = 主 AI 上的 Leave 快照 + `MergeType` / `CompareType` / `CompleteOrder`；判定复用内置 `CollaborateLeaveJudge`：

| 语义 | 锚点 |
|------|------|
| 建 AI 写入设计 Leave | `ActivityInstanceManager.ApplyLeaveSnapshotFromActivity` → `ai_leave_type` / `ai_leave_params` |
| Leave 读取优先级 | `BpmnAssigneeConfigReader.ReadLeave`：AI > BPMN > Legacy |
| 压栈 / 改写子 Leave | `NodeMediatorSignForward.ApplyStackLeaveOnMain` |
| 办结判定 | `NodeMediatorMultiSignForward` → `CheckMIPassRateInfo` / `TryCanLeave` |
| Sequence Waiting | 同 Mediator：Ready 下一挂起子 + `FireActivityReady` |
| 工作台末席 | `IsLastTask`：串行 `CompleteOrder == max(子序)`；中间席不选下一节点 |

## 3. 塌缩与外层席位折叠

### 3.1 塌缩做什么（已落地）

子规则 Passed / NotPassed 时（`NodeMediatorMultiSignForward`）：

1. 完结加签**主容器**（`ActivityState=Completed`）。  
2. `CancelUnCompletedMultipleInstance` 取消仍打开的未完成子。  
3. **`ContinueForward`**（存续期内以 AI 子 Leave 为准，**不再**二次读设计 Leave）。

### 3.2 折叠策略（产品默认 / 演进）

当前实现：**子帧席位即 Leave 分母**（主 AI Collaborate 数本人+加签人）。加签人同意直接计入子 Leave，达阈即出节点。

若将来要「塌缩后只对外记发起人一票、再问设计 Leave」，属产品演进，须另开：恢复/清空 `ai_leave_type` 后再 `TryCanLeave`。**现行不做二次外层判定。**

| 策略 | 现行 | 说明 |
|------|------|------|
| **子帧即离开阈（已落地）** | ✅ | Collaborate 全员过完 → 出节点 |
| **发起人一票再问外层** | ❌ 未做 | 须显式恢复设计 Leave 快照 |

## 4. 与节点 Leave 的叠用

### 4.1 矩阵（产品）

| 设计 Leave（建 AI 时快照） | 后加签（改写 Sequence Collaborate） | 前加签 | 并加签（改写 Parallel Collaborate） |
|---------------------------|--------------------------------------|--------|--------------------------------------|
| **Race** | ✅ 加签后挡住中途抢出；全员过完才 ContinueForward | ✅ 同左 | ✅ 须全员；宿主勿 count=1 |
| **Collaborate** | ✅ 子帧席位凑齐即出 | ✅ | ✅ |
| **Group\*** | 同精神；加签仍改写主 AI 为 Collaborate 子规则 | 同左 | 同左 |

### 4.2 抢办上后加签（已落地路径）

```text
设计 Leave=Race → 建 AI 快照 Race
  └─ SignForwardBehind → 主 AI Leave 改写 Collaborate + Sequence
        本人通过 → Waiting → 唤醒张三（不 ContinueForward）
        张三通过 → Passed → 塌缩主 AI → ContinueForward
```

验收 **SF2**：本人办结后出现加签人待办，**非**直接下一节点选人（`IsLastTask=false`）。

### 4.3 红线

1. 加签**不改** BPMN `sf:leaveJudge`；只改写**主 AI 快照**。  
2. 加签存续期内以 AI 子 Leave 为准；**勿**再假设「Passed 后还要问设计 Race」。  
3. 并加签默认子规则是「凑齐」（Collaborate），不是抢办。  
4. 沟通参与者、抄送**不进** Leave 分母。  
5. 宿主串行前/后加签**禁止**下发 `Count + CompleteOrder=1`（会把首席误判为末席；已由引擎侧禁写 + UI 只传 Type）。

## 5. 选型心智图

```text
节点上多人怎样才算出节点？     → 设计 Leave → 写入 AI 快照（优先读 AI）
办理时临时插人先/后/并审？     → SignForward：压子堆栈 + 改写主 AI Leave
子帧怎样才算结束？             → TryCanLeave(AI) Passed → 塌缩并 ContinueForward
中间席？                       → Waiting（Sequence 唤醒下一席）；IsLastTask=false
抢办上还想「我批完他再把关」？ → 设计 Race + 后加签（引擎改写 Collaborate/Sequence）
抢办上还想「两人一起拍板」？   → 并加签（改写 Collaborate/Parallel 全员）
```

**勿混：**

| 说法 | 别当成 |
|------|--------|
| 后加签本人刚通过 | 可以出节点 / 选二级审批人 |
| 并加签 | 设计期会签节点（Leave=Collaborate 扁平或 SignTogether） |
| 设计 Race | 加签中途仍可一人过就走（加签后已被 Collaborate 盖住） |
| AI Leave 空 | 永远没有 Leave——会回落 BPMN / Legacy |
