## 1. 一句话

**新增一个办理特性 ≈ 新增一个 `FlowOperation` + 一个落在既有族群上的 `*Lane`（只实现 Core）。**

| 层级 | 职责 | 代码 |
|------|------|------|
| `FlowLaneBase` | 工具箱：`TryGate` / `OnFireFlowHook` / `Build*Context`；**不**排统一时序 | `Lanes/FlowLaneBase.cs` |
| 族群 `*LaneBase` | **固化本族钩子清单与顺序**；薄 `Execute` | `Assignee/` · `Transition/` · `Lifecycle/` |
| 动词子类 | **只写** `TryLoadContext` + `ExecuteCore` + `Operation` / `SuccessEvent` | 各族目录下 `*Lane.cs` |

命令入口 DRY 与诊断槽并入本骨架；原 Command Pipeline **不再并列**。

## 2. 类型树（现行）

```text
                         FlowLaneBase（工具箱）
                         │  TryGate / OnFireFlowHook / BuildGate·HookContext
                         │  不排时序、不假设 Task 必有；无事务/锁
                         │
     ┌───────────────────┼───────────────────┐
     │                   │                   │
AssigneeLaneBase    TransitionLaneBase  LifecycleLaneBase
 Load→Gate→Core→Hook  Load→Gate→Core→Hook  Load→Gate→Core→Hook
 （可选 TaskLifecycle） （SkipGate / Runtime） （默认无 TaskLifecycle）
 Context 无 Runtime      Context 独持 Runtime   Context 以 PI 为主
     │                   │                   │
 Transfer / Remove…     Run / SendBack / …    Suspend / Terminate / …
 Consult / AddAssignee…  Start / RunAuto…
```

**路径约定：**

```text
XxxProcess / XxxProcessAsync
  → WorkflowService.RunAction / RunActionAsync   // 事务 + 实例锁（仅 Service）
       → new XxxLane(sail, kit, runner).Execute()
            → 族群：Gate → ExecuteCore → OnFireFlowHook → （族定）TaskLifecycle
```

Lane 为每请求实例（用毕即弃）；**禁止** Lane 内 `beginTransaction` / `InstanceExecutionLock.Acquire`。

## 3. 边界（红线）

| 做 | 不做 |
|----|------|
| 共同父类 = **工具箱**；族群 = **固化钩子时序**；动词 = **只写 Core** | **不**在 `FlowLaneBase` 排全家桶 Gate→Hook |
| 开新族须：钩子模式不同 + 业态对齐 + **改本文** | **不**因「实现方便」开族 |
| 动词走族群 `Execute`，不手写 Gate/AfterSuccess | **不** Override 掉族群时序（除非文档记载的豁免） |
| 事务 + 实例锁：**仅** `WorkflowService`（`RunAction` / `CommitOnSuccess`） | **不**在 Lane / 族群 `Execute` 内开事务或加锁 |
| 图推进 / `IWfRuntime`：**仅** Transition 族 Context | **不**给 Assignee/Lifecycle 胖环境袋；**不**靠 PR 文案禁止调用 |
| 父类复用 Gate/Hook 调用点 | **不**用骨架替代 `AddGate` / `AddHook` / Notifier 产品语义 |
| | **不**把 UserTask Leave / Assignee Resolve 塞进动作骨架 |
| | **不**把 Copyto 塞进三族（独立 `ICopytoNotifier`） |

Assignee 管道（Resolve / Leave / EmptyAction）与本骨架**正交**。

**已记载豁免：** `RejectLane` 在 `RejectMode=Terminate` 时用 `new Execute()` 旁路 Transition 时序，直接委托 `TerminateLane`（成功事件为 `OnProcessTerminated`，`ReasonCode=RejectModeTerminate`）。

## 4. 共同父类 · `FlowLaneBase`

| 成员 | 说明 |
|------|------|
| `Sail` / `Kit` / `Context` | 只读插槽；构造注入（形参常名 `runner`，属性为 `FlowCommandContext Context`） |
| `Operation` | 抽象；Gate / Hook / 审计身份 |
| `BuildGateContext` / `BuildHookContext` | 适配 `FlowCapabilityPipeline` |
| `TryGate` | Reject 时写入 `WfExecutedResult` |
| `OnFireFlowHook` | 对齐旧 `AfterSuccess`（同步 + 异步 Hook） |

**无** `Execute`、**无** `FireTaskLifecycle`——后者由 Assignee 族虚方法按需打开。

## 5. 三族时序与 Context

### 5.1 `AssigneeLaneBase` — 待办人/办理人变化

| 项 | 现行约定 |
|----|----------|
| **业态** | 实例仍运行、BPMN 活动通常不变；改 Task / SignIds·Names 或沟通参与者 |
| **Context** | `AssigneeLaneContext`：TaskView + ActivityInstance + ProcessInstanceId + TaskId；**无** Runtime |
| **时序** | Load → `ConsultPendingGuard` → Gate → `ExecuteCore` → Hook →（可选）`OnFireTaskLifecycleAfterCore` |
| **TaskLifecycle** | `FireTaskLifecycleAfterCore` 默认 **false**（Manager 路径内已通知）；新动词 Manager 不通知时可 Override |

```text
AssigneeLaneBase.Execute
  1. TryLoadContext（Task 必有）
  2. ConsultPendingGuard.TryAllow
  3. TryGate(Operation)
  4. ExecuteCore
  5. OnFireFlowHook(SuccessEvent)
  6. if FireTaskLifecycleAfterCore → OnFireTaskLifecycleAfterCore
```

### 5.2 `TransitionLaneBase` — 流程发生流转

| 项 | 现行约定 |
|----|----------|
| **业态** | 活动实例集合或当前办理位置变化（含加签拓扑） |
| **Context** | `TransitionLaneContext`：PI/AI/TaskId + **internal** `IWfRuntime Runtime`（实现多为 `WfRuntimeManager*`） |
| **时序** | Load →（可选 Gate）→ `ExecuteCore` → Hook；**不**在族内重复 TaskLifecycle |
| **扩展点** | `SkipGate`（RunAuto）；`EnrichGateContext` / `ResolveHookProcessInstanceId`（Start）；`ExecuteWithRuntime`（Factory 预载，如 Run Async） |
| **辅助** | `ExecuteRuntimeAndCopyResult`：`Runtime.Execute` 后拷贝结果字段 |

```text
TransitionLaneBase.Execute / ExecuteWithRuntime
  1. TryLoadContext 或 ToContext(runtime)
  2. unless SkipGate: ConsultPendingGuard → EnrichGate → TryGate
  3. ExecuteCore（常调 ExecuteRuntimeAndCopyResult）
  4. OnFireFlowHook(SuccessEvent)
```

命令级 AfterSuccess **只**在本族 `OnFireFlowHook`；路径内 Mediator/`TaskManager` Notifier **保留**，Lane **禁止再抄**。全表见 [progress A3](../progress/2026-11-15-动作骨架-A3-SendBack.md)。

### 5.3 `LifecycleLaneBase` — 流程实例状态变化

| 项 | 现行约定 |
|----|----------|
| **业态** | 改 `ProcessState`（挂起/恢复/取消/作废/终止） |
| **Context** | `LifecycleLaneContext`：ProcessInstance 为主；Task/AI 可选；**无** Runtime |
| **时序** | Load → Gate → Core → Hook；**默认不** FireTaskLifecycle；**无** `ConsultPendingGuard` |
| **勿混** | 人点 Suspend/Resume ≠ [WaitToken / ResumeWaiting](../talk/草案-挂起与统一Resume.md) |

Terminate 级联待办 `Cancelled` 在 **PIM Core** 内触发，不在族基类默认开。

1. **`FlowOperation` + `EventFireTypeEnum`** 补齐（有子类必有稳定枚举）。

4. Host Handler + 码表（有命令后再进办理条）。

**审查清单（新动词 PR）：**

- 枚举 + 正确族群  
- 未私自改族群时序 / 未手写 Gate·AfterSuccess  
- Core 上下文无越界 Runtime（非 Transition）  
- 未在 Lane 内开事务/加锁  
- 命令级 `SuccessEvent` 只在基类 `OnFireFlowHook` 触发一次；路径内 Notifier 已覆盖则勿再抄

## 8. 与周边机制

| 机制 | 层 | 关系 |
|------|-----|------|
| **本骨架** | 命令扩展主轴 | 枚举 + 族群时序 + 动词 Core |
| **Command Pipeline** | — | **已吸收**，见 [done/草案-命令执行管道.md](../done/草案-命令执行管道.md) |
| **Gate / Hook / Notifier** | 产品横切 | 父类提供调用；**族群固化何时调用** |
| **事务 / 实例锁** | Service（H） | Lane 无事务语义 |
| **Assignee Resolve/Leave** | 算人 / 离开 | 仅 Transition Core 内（如 Approve）调用 |
| **Host Handler** | 按钮 → API | 仍调 `XxxProcess`；内部已派 Lane |
| **ConsultPendingGuard** | Assignee / Transition Gate 前 | 沟通未清时拦部分动词；Lifecycle **不**走 |
