# 进度 · 动作骨架 A3（Transition / SendBack）

> 日期：2026-11-15  
> 设计：[草案-非流转动作骨架.md](../草案-非流转动作骨架.md)

## 已落地

| 项 | 说明 |
|----|------|
| `TransitionActionContext` | 持 `WfRuntimeManager`（internal）；仅 Transition 族 |
| `TransitionActionBase` | Load Runtime → Gate → Execute → `OnFireFlowHook`；**不**在族内重复 TaskLifecycle |
| `SendBackAction` | `CreateRuntimeInstanceSendBack` + `Runtime.Execute`；成功事件 `OnProcessSendBacked` |
| Service | `SendBackProcess*` / `SendBack(kit,…)` → `SendBackAction` |

## Notifier 对账（本刀）

| 层 | 职责 |
|----|------|
| Service / Transition 族 | **唯一** `OnProcessSendBacked` AfterSuccess |
| Mediator / TaskManager | 路径内待办 Created/Cancelled 等 **保留**，Action 不再抄一份 |

## 续：Withdraw（同日）

| 项 | 说明 |
|----|------|
| `WithdrawAction` | `CreateRuntimeInstanceWithdraw` + 共用 `ExecuteRuntimeAndCopyResult` |
| Service | `WithdrawProcess*` / `Withdraw(kit,…)` → Action |
| 基类 | `TransitionActionBase.ExecuteRuntimeAndCopyResult`（SendBack 一并改用） |

## 续：Reject / Close / Jump（同日）

| 项 | 说明 |
|----|------|
| `TransitionNextPerformers` | 自 Service 抽出；Reject=Startup、Close=End、Jump=option |
| `RejectAction` / `CloseAction` / `JumpAction` | 同 Transition 时序 |
| Service | 对应 `*Process` 均改 `RunAction` |

## 续：Run / Resend / Revise / Reverse / SignForward（同日）

| 项 | 说明 |
|----|------|
| `ExecuteWithRuntime` | Factory 预载（`RunProcessAsync`）复用同一 Gate→Core→Hook；`internal`（`WfRuntimeManager`） |
| `ToContext` | `internal` 工厂；各动词 `TryLoadContext` 共用 |
| `RunAction` | `CreateRuntimeInstanceAppRunning`；成功 `OnProcessContinued` |
| `ResendAction` | 保留 `FlattenExceptionFrames` 失败文案 |
| `ReviseAction` | Factory 已 `Success` 则直接返回（不跑 Gate/Execute） |
| `ReverseAction` / `SignForwardAction` | 同 Transition 时序 |
| Service | 上述 `*Process*` 均改 `RunAction` / `RunActionAsync`；`RunProcessAsync` 走 `ExecuteWithRuntime` |
