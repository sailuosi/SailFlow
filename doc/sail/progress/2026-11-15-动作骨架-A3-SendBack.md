## 续：Notifier / Hook 对账表（全动词）

原则：**Service / 族群 `OnFireFlowHook` 拥有命令级 AfterSuccess**；路径内 `FireTaskLifecycle` / 节点级 Hook **保留**；Action **禁止再抄**一份同事件。

### Assignee

| 动词 | Action Hook | 路径内 TaskLifecycle | Action 族内再抄？ |
|------|--------------|----------------------|-------------------|
| Transfer | `OnProcessTransferred` | `TaskManager.Transfer`：`Entrusted`（原待办）+ `Created`（目标） | 否（`FireTaskLifecycleAfterCore=false`） |
| RemoveAssignee | `OnAssigneeRemoved` | `TaskManager.RemoveAssignees`：`Cancelled`（被减人） | 否 |
| ChangeAssignee | `OnAssigneeChanged` | 差量：`Cancelled`（出局）+ `Created`（新人） | 否 |
| Urge | `OnProcessUrged` | 逐条 `Urged`（不改状态） | 否 |
| Delegate | `OnProcessDelegated` | 发起：`Entrusted`+`Created`；办结回转：受托 `Completed` + 原人 `Created` | 否 |

### Lifecycle

| 动词 | Action Hook | 路径内 TaskLifecycle | 备注 |
|------|--------------|----------------------|------|
| Suspend | `OnProcessSuspended` | 无 | 只改 PI 状态 |
| Resume | `OnProcessResumed` | 无 | 只改 PI 状态 |
| Cancel | `OnProcessCanceled` | 无 | 只改 PI |
| Discard | `OnProcessDiscarded` | 无 | 批量 update PI |
| Terminate | `OnProcessTerminated` | 级联收口后逐条 `Cancelled`（PIM 内） | 已补（A2 续） |

### Transition

| 动词 | Action Hook | 路径内待办/节点通知（保留） | Action 再抄？ |
|------|--------------|------------------------------|--------------|
| Start | `OnProcessStarted` | Start→Continue：`Task Insert`→`Created`；节点级 `OnActivityCreated` 等 | 否 |
| Run | `OnProcessContinued` | `TaskManager.Complete`→`Completed`；下一跳 `Created`；整单完另 `OnProcessCompleted`（Runtime） | 否 |
| RunAuto | `OnProcessContinued` | 同 Run（无 Gate） | 否 |
| SendBack | `OnProcessSendBacked` | `TaskManager.SendBack`→`Cancelled`；回退新建→`Created` | 否 |
| Withdraw | `OnProcessWithdrawn` | 同 SendBack 路径（`BackwardType=Withdrawed`） | 否 |
| Reject | `OnProcessRejected` | `Complete` + 兄弟 `Cancel`→`Cancelled`；回退新建→`Created` | 否 |
| Resend | `OnProcessResent` | Mediator 推进：`Completed`/`Created` | 否 |
| Revise | `OnProcessRevised` | `NodeMediatorRevise` 路径内 | 否 |
| Reverse | `OnProcessReversed` | 回退新建→`Created` | 否 |
| Jump | `OnProcessJumped` | Complete 当前 + 目标 `Created` | 否 |
| Close | `OnProcessClosed` | 常到 End：`Completed` + 完结 Hook | 否 |
| SignForward | `OnProcessSignForwarded` | 加签拓扑：`Created`（前/后/并） | 否 |
