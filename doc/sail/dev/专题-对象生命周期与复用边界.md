## 1. 用例三分 + 壳

| 用例 | 一句话 | 并发 |
|------|--------|------|
| **A · 应用级** | 同寿于**一个 `SailClient`**：方言、Gate/Hook/Filter、**四工厂**、Manager/Parser；Builder 可覆写工厂 | 默认可共享 |
| **B · 请求/命令级** | 本请求变化或建造期参数；用毕即弃或 `Clear`；编排袋由 **A 工厂** Create | 一般不能并发 |
| **C · 纯工具** | 无策略纯变换；**不承载可替换工厂** | 可并发 |
| **H · 壳** | `WorkflowService` 薄转发；`SailClientBuilder` 仅 Build 前可变 | 壳随 Host |

**应用级口径**：锚点是**一个 `SailClient` 实例**（Host 可再 Singleton）。多 Client = 多套 A，不是进程上帝。

**口诀**：注册表 / Builder 可换 / 每 Client 共享 → **A**；一次请求或建造在变 → **B**；无字段纯变换 → **C**；Host 薄壳或 Build 期 → **H**。

---

## 2. 原则

1. 先归用例，再定寿命档位；一类一档，写明「同寿于谁」。
2. 依赖只指向更长寿或同寿；**禁止**长寿持短寿可变态。
3. 请求变化 → B；共享能力 → A；无策略变换 → C。
4. **A 不吸 B**（偏函数式）：变化进 Context / 入参袋；A 吃参数，不持 Runner/kit 字段。
5. 与程序集分层正交：包边界 ≠ 寿命 ≠ A/B/C。

---

## 3. A / B / C / H 规范

### 3.1 A

| 项 | 约定 |
|----|------|
| 典型 | `SailClient`、Dialect、已注册 Filter/Gate/Hook/Notifier、`*Manager`、引擎工厂、`InstanceExecutionLock` |
| 持有 | 长寿依赖、注册表、可选**线程安全**只读缓存；协调器用并发字典 |
| 禁止 | 本次 Runner / kit / User / LinkContext；**跨 Client 共享**同一工厂/Manager 实例 |
| 寿命 | **L-App** |

### 3.2 B

| 项 | 约定 |
|----|------|
| 形态 | ① 入参/上下文袋：`FlowCommandContext`（基型 `WfAppRunner`）、`ActivityForwardContext`、Gate Context、kit ② 建造器：`RunBuilder` |
| 编排袋 | `WfRuntimeManager*` / `NodeMediator*` / `NodeSendBack*` —— **B**，勿当 A |
| 禁止 | 升应用单例；未 Clear 被第二请求复用；袋内自建注册表 |
| 寿命 | **L-Cmd** |

#### B.0 编排袋字段白名单

允许：本命令导航态（`AppRunner`、`Kit`、`ProcessModel` 使用期引用、`RunningActivityInstance`、`TaskView`、`ActivityResource`、`LinkContext`、`BackwardContext`、`SendBackOperation`、执行结果）；对 A 的**只读引用**（`Sail` / Factories）——**不缓存 Manager 实例字段**，不 `new Manager`。

禁止：自建注册表；拷贝 Gate/Hook 列表；实例级「当前用户」当全局。

#### B.1 结束策略

| 策略 | 约定 |
|------|------|
| **用毕即弃** | Runtime / Mediator / kit / GateContext：不回收，下次重建 |
| **Clear** | 复用同一 Builder/袋前须 `Clear()` ≡ 空袋；Clear 前禁止他请求使用 |
| **禁止** | 半 Clear |

### 3.3 C

无实例可变状态；典型：`EnumHelper`、`ConvertHelper`、`NextActivityComponents`。禁止 ThreadStatic 偷运 Context；禁止把可覆写工厂做成不可替换 static。

### 3.4 H

| 项 | 约定 |
|----|------|
| `WorkflowService` | 持 A（`Sail`）；**不扣 B**；无 `_wfAppRunner` |
| `SailClientBuilder` | 仅 Build 前可变；Build 后冻结进 Client |

#### H.1 命令路径

```text
SailClient（A）
  └─ CreateRunBuilder(…) → RunBuilder（B）
        .Use* …
        .Build() / .BuildCommandContext() → FlowCommandContext（入参袋 B）
              └─ WorkflowService / Executor（H，无状态）
                    └─ RuntimeFactory.Create* → WfRuntimeManager*（执行编排袋 B）
                          └─ MediatorFactory.Create* → NodeMediator*（执行编排袋 B）
```

| 角色 | 档 | 约定 |
|------|-----|------|
| `CreateRunBuilder` | A 上的方法 | 每次 new；Client **无** Runner 属性 |
| `RunBuilder` | B 建造期 | 链式 `Use*`；≠ 入参袋 |
| `FlowCommandContext` | B 入参 | `Build` 产物；基型 `WfAppRunner` |
| Runtime / Mediator | B 编排 | 吃入参；用毕即弃 |
| `WorkflowService` | H | 只转发 |

**已否决**：Service/Client **属性**挂 Runner；永久扣袋靠 Clear；砍尽链式。

## 4. 寿命档位

| 档位 | 同寿于 | 主要用例 |
|------|--------|----------|
| **L-App** | 一个 `SailClient` | A |
| **L-Scope** | ASP.NET Scope | H（`WorkflowService`） |
| **L-Cmd** | 一次 Start/Run/… | B |
| **L-Call** | 单次语句 | 短命碎片 |
| **L-Ephem** | 任意次 `new` | 不推荐用于 Manager / 引擎工厂 |

依赖：短寿 → 长寿 / 同寿；禁止反向持可变短寿。

---

## 5. 四工厂槽（A）

挂 `SailClient`；`SailClientBuilder.UseXxxFactory` 可覆写。禁止进程级不可覆写 Factory 表面。

| 槽 | 默认 | Create 产物 |
|----|------|-------------|
| `RuntimeFactory` | `DefaultRuntimeFactory` → `RuntimeInstanceCreator` | `WfRuntimeManager*`（B） |
| `MediatorFactory` | `DefaultMediatorFactory` → `MediatorInstanceCreator` | `NodeMediator*` / Event / SendBack（B） |
| `ProcessModelFactory` | `DefaultProcessModelFactory` | `IProcessModel`（使用期随 B；**缓存属本 Client**） |
| `ManagerFactory` | `DefaultManagerFactory` | Manager / Parser（A，懒持有；**唯一** `new` 入口） |

**Manager**：经 `client.ManagerFactory` 拿；**不**在 Client 上挂齐 Activities/Tasks… 属性。

**ProcessModel**：在途 B **沿用创建时模型引用**；缓存失效 / 换版只影响之后的 Create。

## 6. 类型落位（规范）

| 类型 | 档 | 说明 |
|------|-----|------|
| `SailClient` / Dialect / Gate·Hook·Filter | A | |
| `*Manager` / Parser·Checker·Resolver | A | 仅 `ManagerFactory` 创建 |
| 四工厂 | A | Builder 可覆写 |
| `RunBuilder` | B | Client 方法每次 new |
| `FlowCommandContext` / `WfAppRunner` | B | 入参袋 |
| `WfRuntimeManager*` / `NodeMediator*` / `NodeSendBack*` | B | 执行编排袋；B.0 |
| `ActivityForwardContext` / kit | B | |
| `EnumHelper` / `ConvertHelper` / `NextActivityComponents` | C | |
| `WorkflowService` | H | 无状态转发 |
| `SailClientBuilder` | H·组合根 | Build 前 |

## 7. 检查清单

新增或改类型时：

1. 归 A / B / C / H？（编排袋点名 B；引擎工厂不得标 C）
2. 寿命档？同寿于哪个 `SailClient` / 哪次命令？
3. 是否持有更短寿的可变态？
4. 若 A：有无 Runner/kit 字段？缓存是否线程安全？
5. 若 B：用毕即弃还是 Clear？是否遵守 B.0？
6. Manager / Parser 是否只经 `ManagerFactory`？
