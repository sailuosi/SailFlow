# 下一节点候选管道（Next Step Route）— 演算前后扩展基准

> 状态：**已落地（S0–S2）** — 2026-11-13；S3 可选（Python Evaluator / 宿主正式 Prepare·权限包 / 前端消费 Disabled）  
> 动机：结构演算本可产出**多个目标节点**并由前端选择；业务需要在演算前补条件、演算后裁剪/标注候选，且条件求值可替换；不得改写调度内核或与 Assignee / Gate / Script 搅在一起  
> 使用事实：[../helps/教程-连线条件与后续节点演算.md](../helps/教程-连线条件与后续节点演算.md)  
> 关联：[特性说明-引擎能力基线.md](./特性说明-引擎能力基线.md) · [特性说明-待办人管道.md](./特性说明-待办人管道.md) · [特性设计-回调与事件.md](./特性设计-回调与事件.md) · [架构设计-项目依赖与分层.md](./架构设计-项目依赖与分层.md) · [最佳实践-宿主能力包UseXxx.md](./最佳实践-宿主能力包UseXxx.md)

本文是「下一跳候选 + 条件求值」扩展的**硬基准**：条件袋（Prepare）/ 条件求值（`IConditionEvaluator`）/ 候选 Filter 的挂点、Match、对称性与红线以本文为准。产品讨论可改口径；**与本文冲突时以本文为准**（落地后改为「本文 + 代码契约」）。

**命名备忘：**  
- 演算前写袋：注册 **`IfCondition*`** → **`INextStepPrepare`**；推荐基类 **`NextStepPrepare`**。  
- **下一跳计算管道（同一 `UseNextStepRoute`）三件套：**  
  1. 写袋：`IfCondition*` → `INextStepPrepare`  
  2. 求值：`AddConditionEvaluator` / `UseConditionEvaluator`（子 Builder 方法）→ **`IConditionEvaluator`**（默认 ≡ `ExpressionParser`）  
  3. 裁候选：`AddFilter` → `INextStepFilter`  
- **不另立**顶层独立于 NextStepRoute 的条件求值 `UseXxx` 作为正典（避免与节点计算管道分裂）；若保留 Client 补挂别名，须转发进同一注册表。  
- **Match 正典 = 注册 Options**（三件套同源字段）；链式糖展开为同一 Options。  
- **≠ IronPython Script**：条件求值若用 Python，必须是管道内 **`IConditionEvaluator`**，不是 ScriptMethod。

## 0. 已决决议（定型口径）

| # | 主题 | 决议 |
|---|------|------|
| **N1** | **两时刻正交** | **演算前 = Prepare（条件袋 / IfCondition）**；**演算后 = 候选节点 Filter**。禁止用 Filter 代替连线表达式做金额分流；禁止用 Prepare 改候选列表；禁止用 Gate 注入变量或改候选。 |
| **N2** | **预览 ≡ 发送同源** | Client 级 `IfCondition`→`INextStepPrepare` 链与 NextStep Filter 链必须挂在**同一 Client 级注册表**；`GetNextStepInfo` / 结构下一步查询与 `GetNextActivityTreeListRuntime`（发送裁剪前）**共用同一管道入口**。禁止只 Prepare 于预览、或只 filter 发送。 |
| **N3** | **不进结构内核 / Mediator** | `ProcessModelBPMNCore` 保持纯图遍历；`NodeMediator` 仍只消费已算好的下一步树。扩展挂 **Parser / 路由管道**（A 类插槽，同寿于 `SailClient`），对齐 Assignee「不改 Mediator」。 |
| **N4** | **多目标 + 前端自选仍是默认** | 管道默认**不**强制单选。Filter 可收窄/标注；最终仍以 Runner `NextActivityPerformers` 键集合为准（发送二次过滤）。收成 0 个候选 → 可诊断失败，不得静默挑一条。 |
| **N5** | **And 并行不可静默删支** | **AndSplit / AndSplitMI** 语义上的必达支路：NextStep Filter **禁止**静默移除；至多标注告警或交由 **Gate Reject**。Or / XOr / 前端多选集合才是 Filter 主战场。 |
| **N6** | **字段分流优先 BPMN** | 业务字段（金额、部门码等）优先写在 `conditionExpression` + **IfCondition 补键**；NextStep Filter 承接**产品策略**（权限可见、强制单选、隐藏非法支路、排序），避免把可设计器配置的规则搬进代码导致图失真。 |
| **N7** | **与 Assignee / Gate 三线分离** | 改「走哪几个节点」≠ 改「谁来办」≠ 「推进前合规拒绝」。Assignee Filter / EmptyAction / 锚点 Job 见待办人管道；Gate 见回调与事件。本特性**不**注册成 `IAssigneeResolver` Type，**不**实现 `IFlowGate`。 |
| **N8** | **注册 API：单一管道 `UseNextStepRoute`** | 下一跳**节点计算管道**只此一门：子 Builder 上 **`IfCondition*`**（Prepare）+ **`AddConditionEvaluator` / `UseConditionEvaluator`**（求值）+ **`AddFilter`**（候选）。**注册序 / Order = 执行序**。**不废**请求级 `RunBuilder.IfCondition`。教程主推糖；接口留给扩展作者。 |
| **N9** | **可达性红线** | Filter **不得**插入 BPMN 图上从当前节点不可达的 `ActivityId`；Prepare **不得**伪造令牌/跳过结构演算。强制跳转仍走既有跳转/退回/`SkipDetail` 命令路径。 |
| **N10** | **诊断强制** | Prepare 写入的键、Filter 移除/禁用的节点、ReasonCode、Match 未命中跳过须可观测。禁止静默改候选导致「界面有、发送无」无从排查。 |
| **N11** | **条件袋两档同义、寿命不同** | **请求级** `RunBuilder.IfCondition` 与 **Client 级** `UseNextStepRoute → IfCondition*` **写入同一 `Conditions` 袋**。差别仅在谁写/何时写/活多久。禁止把 Filter 叫 IfCondition；禁止废掉请求级。 |
| **N12** | **Match：Options 正典 + IsMatch 辅** | 生效范围以注册 Options 为准（对齐 Gate/Hook：`Match` / `ProcessCodes` / `ProcessIds` / `ActivityCodes` / **`ProcessCodePatterns`** / `Order`）。Prepare / Filter / **Evaluator**：**先 Options → 再 `IsMatch` → 再业务方法**。链式糖展开为同一 Options，**禁止双真相**。Prepare 上**禁止**复刻 `UseProcess`/`OnTask`。`IsMatch` 默认 `true`。 |
| **N13** | **条件求值契约化（属 NextStep 管道）** | 今日静态 `ExpressionParser` → **`IConditionEvaluator`**，挂在 **`UseNextStepRoute`** 上（`AddConditionEvaluator` / 子 Builder `UseConditionEvaluator`）。**返回 `bool?`：`true`/`false` = 求出并终止链；`null` = 交下一 Order。** `null` ≠ `false`。 |
| **N14** | **Evaluator 有序链 + Match** | 与 Prepare/Filter 同属节点计算管道；按 **`Order` 升序**；N12 同源 Match。默认 LINQ 实现 `Order` 宜偏大作兜底。未额外注册时行为 ≡ 今日 `ExpressionParser`。 |
| **N15** | **与 Script/IronPython 分轨** | 连线 / Conditional / 变量条件求值**不**走 `IScriptMethodHandler`。Python 条件若提供，必须是 **`IConditionEvaluator` 实现**（ext），不得冒充 ScriptMethod。 |

## 1. 目标与非目标

### 1.1 目标

- 在**不破坏**「结构演算 → 多候选 → 前端自选 → 发送按选中键裁剪」主路径的前提下，提供：  
  - **演算前**条件袋补全——与 `IfCondition` **同一心智**；支持 Match；  
  - **条件表达式求值可替换**——`IConditionEvaluator` 有序链（`bool?` 移交）；  
  - **演算后**候选节点处置，同一套 Match Options。  
- 预览与发送**行为一致**、可诊断。  
- 扩展只挂 Client 管道；多数宿主零继承用糖即可。

### 1.2 非目标

- 不取消 BPMN `conditionExpression` / 网关语义（换的是**求值引擎**）。  
- 不做下一跳办理人解析（Assignee）；不做推进前合规拒绝（Gate）。  
- 不把 Host 业务表 / IronPython 引进 pure。  
- 首期不做设计器「求值语言」配置。  
- 不把 `SetVariable` 与条件袋混名。  
- **不在 Prepare 链上提供 `UseProcess`/`OnTask`**（N12）。  
- **不用 Script 节点执行冒充连线条件求值**（N15）。

## 2. 概念（勿混用）

| 术语 | 含义 |
|------|------|
| **结构演算** | 出边 + 连线条件 + 网关展开 → 候选活动 |
| **条件袋** | `Conditions` / `ConditionKeyValuePair` / 查询 `condition` |
| **IfCondition（请求级 · B）** | `RunBuilder.IfCondition`：单次命令写袋 |
| **IfCondition（Client 级 · A）** | `UseNextStepRoute` 注册：每次演算前写同一袋 |
| **时刻 R0 · Prepare** | 结构演算前：变量合并后跑 Client Prepare |
| **时刻 R1 · Filter** | 结构演算后：处置候选集合 |
| **`NextStepRouteOptions`** | 注册条目上的 Match / Order（**正典**） |
| **`IsMatch(ctx)`** | Options 已命中后的第二道门；默认 true |
| **Prepare** | `INextStepPrepare`；推荐基类 `NextStepPrepare`；**只写条件袋** |
| **`IConditionEvaluator`** | 条件表达式求值契约；`TryEvaluate` → `bool?`；有序链（N13–N14） |
| **NextStep Filter** | `INextStepFilter`：只碰候选 |
| **链式糖** | `ForProcess` / `ForActivity` / `Matching` / 袋内 `IfCondition` → 展开为 Options |

易混：

- **两档 IfCondition** 对表达式同义，对调用方不同寿（N11）。  
- **Prepare（写袋）** ≠ **Evaluator（求值）** ≠ **Filter（裁候选）**。  
- **`bool?` null**（换下一 Evaluator）≠ **`false`**（条件不成立）。  
- **`IConditionEvaluator`** ≠ **`IScriptMethodHandler` / IronPython Script**（N15）。  
- **`ForProcess`（Match 糖）** ≠ **`RunBuilder.UseProcess`**。  
- Prepare / Filter / Evaluator ≠ Gate / Assignee Filter。

## 4. 目标形状（增量方案）

### 4.1 条件袋两档（N11）

```text
请求级 B：RunBuilder.IfCondition(...)
Client 级 A：UseNextStepRoute → IfCondition* → INextStepPrepare
→ 同一 Conditions → IConditionEvaluator 链（默认 LINQ ≡ ExpressionParser）
```

### 4.2 管道与 Match 短路（N12 / N14）

```text
UseNextStepRoute  —— 下一跳节点计算管道（唯一注册门面）
  ├─ Prepares[]    + Options   R0 写袋          ← IfCondition*
  ├─ Evaluators[]  + Options   结构演算内求值   ← AddConditionEvaluator / UseConditionEvaluator
  └─ Filters[]     + Options   R1 裁候选        ← AddFilter

Prepare / Filter 每项：
  1) Options Match → 2) IsMatch → 3) Prepare / Filter

Evaluator 链（每次求一条 conditionExpression；属同一管道）：
  foreach（Order 升序，同 Order 注册序）:
    1) Options Match 未命中 → skip
    2) IsMatch? == false → skip
    3) r = TryEvaluate(ctx)
       true / false → 采用，停止链
       null         → 下一执行器
  若皆 null → 默认视为 false + 可诊断（兼容今日吞异常；可配置，实施时定）
```

```text
请求级 IfCondition + 流程变量 + Client Prepare[]（已 Match）
  → 结构演算（出边条件经 IConditionEvaluator 链求值）
  → Filters[]（已 Match）
  → 预览 NodeView / 发送再按 NextActivityPerformers 裁剪
```

### 4.3 边界

| 层 | 挂载 |
|----|------|
| 字段分流（图上表达式） | BPMN `conditionExpression` |
| 单次字面量 | 请求级 `RunBuilder.IfCondition` |
| 自动补键 + 范围 | Client `IfCondition*` + Options（Prepare） |
| **表达式怎么算** | **`IConditionEvaluator` 链**（默认 LINQ；可换 Python 等） |
| 候选可见性 | `AddFilter` + Options |
| Script 节点跑脚本 | `UseIronPython` / ScriptMethod（**不是**条件求值） |
| 算人 / 拒发 | Assignee / Gate |

## 5. API 形态（定型）

### 5.1 启用与注册（主推示例）

对齐 Gate/Hook 的 **Options 参数模式**为 Match **正典**；链式为糖。

```csharp
// 请求级（现行 · 保留）—— 选定本次办理，不要与 Client 注册混淆
await sail.CreateRunBuilder()
    .UseApp(...)
    .UseProcess(processId)
    .OnTask(taskId)
    .IfCondition("amount", "15000")
    ;

// Client 级 —— 下一跳节点计算管道（唯一门面）
builder.UseNextStepRoute(r =>
{
    // —— R0 写袋：Prepare ——
    r.IfCondition<OrderAmountPrepare>(o =>
    {
        o.ProcessCodes = new[] { "EXPENSE", "PAYMENT" };
        o.ActivityCodes = new[] { "dept_approve" };
        o.ProcessCodePatterns = new[] { "^FIN_.*" };
        o.Match = NextStepMatch.Whitelist;
        o.Order = 20;
    });
    r.IfCondition("needFinance", "1");
    r.IfCondition(c => c
        .ForProcess("EXPENSE")
        .ForActivity("dept_approve")
        .Matching("^FIN_.*")
        .IfCondition("routeFlag", "A")
        .IfCondition("dept", "finance"));
    r.IfCondition(ctx =>
    {
        ctx.Conditions["amount"] = ReadAmount(ctx.AppInstanceId);
    }, o => o.ProcessCodes = new[] { "EXPENSE" });

    // —— 结构演算内求值：Evaluator（同管道；勿另开顶层 UseXxx 正典）——
    r.AddConditionEvaluator<PythonConditionEvaluator>(o =>
    {
        o.Order = 10;                              // 优先；null 则落到默认 LINQ
        o.ProcessCodes = new[] { "EXPENSE" };
        o.ProcessCodePatterns = new[] { "^FIN_.*" };
    });
    // 默认可由引擎在启用管道时挂 LinqDynamicConditionEvaluator(Order=100, Match=All)
    // 或显式：r.UseConditionEvaluator<LinqDynamicConditionEvaluator>(o => { o.Order = 100; o.Match = All; });

    // —— R1 裁候选：Filter ——
    r.AddFilter<PermissionHideBranchFilter>(o =>
    {
        o.ProcessCodes = new[] { "EXPENSE" };
        o.Order = 30;
    });
});
```

| 注册物 | 说明 |
|--------|------|
| `IfCondition*` | → `INextStepPrepare`；写条件袋 |
| **`AddConditionEvaluator` / `AddConditionEvaluator<T>`** | → `IConditionEvaluator`；**正典** |
| **`UseConditionEvaluator` / `UseConditionEvaluator<T>`** | 与 Add* 等价糖（子 Builder 上，**不是**顶层独立管道） |
| `AddFilter` / `AddFilter<T>` | → `INextStepFilter`；裁候选 |

**角色分层（降低抽象感）：**

| 谁 | 用法 |
|----|------|
| 多数宿主 | `IfCondition` 糖写袋；默认 Evaluator 即可 |
| 可复用写袋 / 求值 | `IfCondition<T>` / `AddConditionEvaluator<T>` |
| 查单 + 动态门控 | 继承 `NextStepPrepare` 或实现 `IConditionEvaluator` |

### 5.2 `NextStepRouteOptions`（Match 正典 · N12）

对齐 [特性设计-回调与事件.md](./特性设计-回调与事件.md) 的 Gate/Hook 过滤字段，并增补正则：

| 字段 | 语义 |
|------|------|
| `Match` | `Whitelist`（默认）/ `All`（显式） |
| `ProcessCodes` | 流程**定义**编码精确匹配（非实例 Id；推荐业务稳定键） |
| `ProcessIds` | 可选，与 Gate 一致 |
| `ProcessCodePatterns` | 流程编码**正则**；与 `ProcessCodes` 为 **或** 关系（命中任一即可进入流程维） |
| `ActivityCodes` | **当前节点** ActivityCode（演算出发点）；未配则不限节点 |
| `Order` | 执行序；同 Order 按注册序 |

**短路顺序（定死）：**

1. `Match == All` → 通过流程/节点维（仍可走 `IsMatch`）。  
2. 否则：流程维 = `ProcessCodes` 命中 **或** `ProcessCodePatterns` 命中 **或** `ProcessIds` 命中；皆空且非 All → **不命中**（与 Gate Whitelist 空集策略实施时对齐；建议文档/单测写清「空白名单 = 不匹配」）。  
3. 若配置了 `ActivityCodes`：当前节点须命中。  
4. `IsMatch(ctx)`。  
5. `Prepare` / `Filter`。

Prepare 与 Filter **共用**该 Options 类型（或同源字段），避免两套 Match 方言。

### 5.3 契约与推荐基类

```csharp
public enum NextStepMatch { Whitelist, All }

public sealed class NextStepRouteOptions
{
    public NextStepMatch Match { get; set; } = NextStepMatch.Whitelist;
    public string[] ProcessCodes { get; set; }
    public string[] ProcessIds { get; set; }
    public string[] ProcessCodePatterns { get; set; }  // 正则
    public string[] ActivityCodes { get; set; }
    public int Order { get; set; }
}

public interface INextStepPrepare
{
    /// <summary>Options 已命中后的第二道门。默认实现 true。</summary>
    bool IsMatch(NextStepRouteContext ctx);

    /// <summary>写入 Conditions。禁止慢外部 HTTP。</summary>
    void Prepare(NextStepRouteContext ctx);
}

public interface INextStepFilter
{
    bool IsMatch(NextStepRouteContext ctx);  // 默认 true；与 Prepare 对称
    void Filter(NextStepRouteContext ctx, NextStepCandidateList candidates);
}

/// <summary>推荐基类：默认 Prepare 冲刷静态袋 + Contribute；IsMatch 默认 true。</summary>
public abstract class NextStepPrepare : INextStepPrepare
{
    public virtual bool IsMatch(NextStepRouteContext ctx) => true;

    public virtual void Prepare(NextStepRouteContext ctx)
    {
        FlushLiteralBag(ctx);
        Contribute(ctx);
    }

    /// <summary>动态补键（读单据等）。默认空。</summary>
    protected virtual void Contribute(NextStepRouteContext ctx) { }

    // 供子类构造期声明静态键（可选）
    protected void IfCondition(string name, string value) { /* 收入静态袋 */ }
}

public sealed class NextStepRouteContext
{
    public SailClient Sail { get; }
    public FlowCommandContext Runner { get; }    // 可空
    public string ProcessId { get; }
    public string ProcessCode { get; }           // Match 用
    public string Version { get; }
    public string CurrentActivityId { get; }
    public string CurrentActivityCode { get; }   // Match 用
    public string ActivityInstanceId { get; }
    public IDictionary<string, string> Conditions { get; }
    public NextStepRoutePhase Phase { get; }     // Preview | Send
    // AppInstanceId / UserId / ProcessInstanceId …
}

public enum NextStepRoutePhase { Preview, Send }

public sealed class NextStepCandidateList
{
    public IList<NextStepCandidate> Items { get; }
}

public sealed class NextStepCandidate
{
    public string ActivityId { get; }
    public Activity Activity { get; }
    public bool Disabled { get; set; }
    public bool Required { get; set; }
    public string ReasonCode { get; set; }
}
```

链式糖建造器（示意；**只产生一份 Options + 袋**）：

```csharp
// INextStepConditionBagBuilder
//   ForProcess(params string[] codes)
//   ForActivity(params string[] codes)
//   Matching(params string[] regexPatterns)
//   IfCondition(string name, string value)
// 禁止：UseProcess / OnTask / UseApp
```

### 5.4 管道入口

| 方法 | 行为 |
|------|------|
| `Prepare(ctx)` | 变量合并后：按序 Options → IsMatch → Prepare；写回 Conditions |
| `Filter(ctx, list)` | 结构结果后：按序 Options → IsMatch → Filter |

未启用管道：no-op。

### 5.5 诊断

| 场景 | 期望 |
|------|------|
| Options 未命中 | 可 debug 跳过原因（可选）；不写袋 |
| Prepare 写键 | 记录 key + 实现类型 |
| `IsMatch == false` | 可诊断与 Options 未命中区分 |
| Filter 移除 / 0 候选 / Required 未选 | ReasonCode + Message |
| Evaluator 返回 `null` / 全链 `null` | 可诊断；与「条件为 false」区分 |

### 5.6 条件求值：`IConditionEvaluator`（N13–N15）

> 属 **`UseNextStepRoute` 节点计算管道** 的一环（写袋 → **求值** → 裁候选）。替换今日对 `ExpressionParser` 的静态调用点（`IsValidTransition` / Conditional / 变量校验等），**不**改变 BPMN 表达式配置位置。

#### 注册（仅子 Builder；正典）

见 §5.1。再摘：

```csharp
builder.UseNextStepRoute(r =>
{
    r.AddConditionEvaluator<PythonConditionEvaluator>(o =>
    {
        o.Order = 10;
        o.ProcessCodes = new[] { "EXPENSE" };
        o.ProcessCodePatterns = new[] { "^FIN_.*" };
        o.ActivityCodes = new[] { "xor_split" };
    });
    r.UseConditionEvaluator<LinqDynamicConditionEvaluator>(o =>
    {
        o.Order = 100;
        o.Match = NextStepMatch.All; // 兜底
    });
});
```

Options 字段与 §5.2 **同源**；可复用 `NextStepRouteOptions` 或别名，**禁止**另套字段名。  
**禁止**再提供与管道脱钩的顶层 `builder.UseConditionEvaluator` 作为第二真源（若为便利保留，必须写入**同一** Evaluators 注册表）。

#### 契约示意

```csharp
public interface IConditionEvaluator
{
    /// <summary>Options 已命中后的第二道门；默认 true。</summary>
    bool IsMatch(ConditionEvaluateContext ctx);

    /// <summary>
    /// true/false = 求出结果并终止链；
    /// null = 本执行器无法处理或求值失败，交给下一 Order。
    /// </summary>
    bool? TryEvaluate(ConditionEvaluateContext ctx);
}

public sealed class ConditionEvaluateContext
{
    public string Expression { get; }                       // conditionExpression / Trigger 表达式原文
    public IDictionary<string, string> Variables { get; }   // 已合并的条件袋
    public string ProcessId { get; }
    public string ProcessCode { get; }
    public string CurrentActivityId { get; }
    public string CurrentActivityCode { get; }
    public string TransitionId { get; }                     // 可选
    public NextStepRoutePhase Phase { get; }                // Preview | Send
}

// 默认实现：封装今日 ExpressionParser.ReplaceParameterToValue + Parse
// public sealed class LinqDynamicConditionEvaluator : IConditionEvaluator { ... }
```

#### `bool?` 语义（定死）

| 返回值 | 含义 | 链行为 |
|--------|------|--------|
| `true` | 条件成立 | **停止**，采用 true |
| `false` | 条件不成立 | **停止**，采用 false |
| `null` | 本器跳过/失败 | **继续**下一 Order |

#### 与现行 `ExpressionParser` / IronPython

| 项目 | 定型 |
|------|------|
| 默认行为 | `LinqDynamicConditionEvaluator` ≡ 今日静态解析；未挂扩展时零差异 |
| 静态类 | 可保留为默认实现内部工具；业务调用点改走 Evaluator 槽 |
| IronPython Script | **仍只**服务 Script/Action 节点；**不是**默认条件引擎 |
| Python 条件（可选 ext） | 另实现 `IConditionEvaluator`；对不认识的表达式返回 `null` 以回落 LINQ |

## 6. 约束（实施必须遵守）

1. **同源（N2）。**  
2. **Match 单真源（N12）：** 注册表只存一份 Options；链式糖必须展开写入该 Options，禁止另存「链式 Match」并行求值。  
3. **短路顺序** 见 §4.2 / §5.2 / §5.6；实现类**不要**在业务方法里重复手写 ProcessCodes 白名单。  
4. **条件袋合并：** 请求级 → 流程变量 → Client Prepare（已 Match）→ **Evaluator 链求值** → 结构展开；后写覆盖可诊断。  
5. **Evaluator：** `null` 与 `false` 语义不得混淆；全链 `null` 的默认策略须单测锁定（建议 false + 诊断）。  
6. **AndSplit（N5）** 不可静默删支。  
7. **性能：** 默认同步；禁默认慢 HTTP/MQ。  
8. **分层：** 契约在 pure；LINQ 默认可在 pure；Python Evaluator 在 ext；查单 Prepare 在 Host/biz。  
9. **可选启用：** 未 `UseNextStepRoute` / 未额外 Evaluator ≡ 现行行为（内置 LINQ 兜底）。  
10. **Filter 之后**仍走 `NextActivityPerformers` 裁剪。  
11. **命名 / 门面：** 一律经 `UseNextStepRoute`；子方法 `IfCondition*` / `AddConditionEvaluator`（及 `UseConditionEvaluator` 糖）/ `AddFilter`；契约 `INextStepPrepare` / `IConditionEvaluator` / `INextStepFilter`。

|------|------|
