# sailflow · doc

文档按**读者角色**与**成熟度**分三仓；现行可执行规范以 `sail/` 为准。

| 目录 | 面向 | 用法 |
|------|------|------|
| [sail/](./sail/) | 引擎演进、宿主接线 | **现行规范**；特性说明 / OA 专题 / theme / 设计 / 活动清单 |
| [helps/](./helps/) | 接入、日常开发、对外叙事 | 教程 / 指南 / 博文底稿；细节回链 `sail/` |
| [audit/](./audit/) | 决策前对照 | **只读**；拍板后再进 `sail` 草案或行动计划 |

速览：

- 能力契约入口 → [sail/特性说明-引擎能力基线.md](./sail/特性说明-引擎能力基线.md)
- 能力成熟度雷达（文档梳理）→ [sail/目录-能力成熟度.md](./sail/目录-能力成熟度.md)
- 用户指南索引 → [helps/README.md](./helps/README.md)
- 产品壳（菜单 / Host API / UX）→ 宿主仓 `sleveen-admin/doc/sailflow-features.md`

`sail/` 内分层：`特性说明` → `OA/`（产品策略）→ `theme/`（内部怎么做）→ `talk/`（未升格）→ `progress/` / `done/`（落地与归档）。
